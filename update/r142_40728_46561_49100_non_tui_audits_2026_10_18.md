# Non-TUI audits: MCP permissions, catalog URLs, plugin HTTP pooling

## `#40728` Attachment-owned MCP permissions

Go publishes per-server permission authority for each enabled MCP runtime; a
server with no published authority has its calls and elicitations rejected
rather than inheriting another owner's profile. MCP permission-authority tests
pass.

## `#46561` Explicit provider model catalog URLs

An explicit catalog URL keeps its own query/path, gains provider identity, and
a custom inference base URL alone does not enable API-key discovery. Model
catalog URL and discovery-gate tests pass.

## `#49100` Remote plugin HTTP connection pooling

Remote plugin service configuration can reuse the owner's HTTP pool while
retaining the current endpoint, product SKU, and authentication; a service
without a doer or pool keeps its fallback behavior. Plugin HTTP tests pass.

## Verification

- `go test ./mcp -run 'PermissionAuthority|Attachment|Permissions' -count=1`
- `go test ./model -run 'ModelCatalogURL|DiscoveryGate|APIKey' -count=1`
- `go test ./plugin -run 'RemoteHTTP|Pool|Reused' -count=1`
