  schema is copied verbatim from Rust `local.rs`.

  `posts_roots_created ON posts(board,channel,timestamp,seq) WHERE id=root`.
- #47036: Rust shares `Arc<JsonValue>` across code-mode cells. Go's code mode
  runs through the stdio/process host protocol and has no in-process cell store
  that deep-copies payloads, so the optimization has no Go counterpart.
