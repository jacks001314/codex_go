# Rust #40688: bounded diagnostic SQLite integrity checks

Upstream commit: `32ce703a80ef8828a07d452e2af5630cc0825aae`

## Result

Equivalent implementation in the Go doctor.

- Feedback attachment collection (`Options.Feedback`) gives each runtime
  database integrity scan a one-second deadline. Direct `doctor` checks pass a
  zero deadline and stay unbounded.
- A scan interrupted by the deadline with only clean rows so far reports a
  warning; corruption rows returned before the interruption are retained and
  report a failure.
- Missing database files are skipped as OK, matching Rust's `path.is_file()`
  branch.
