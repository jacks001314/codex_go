# Round 1302 — run the gap suites on real Linux and macOS hosts

Rust target: `67f0994b532b8740f14b5b738af7b7b2a915b1d6` (anchor worktree
`D:\qax\reagent\dev\git\codex-anchor-67f0994b`, hash `67f0994b`).

Everything in this round comes from running the Go suites on the two real Unix
hosts in `pl.txt` instead of trusting Windows compile checks. Two classes of
finding: real product defects that only a Unix host can show, and fixtures that
encoded a Windows-only assumption about paths, keyrings or `ps`.

## Product defects

- `sandbox/linuxsandbox`: `daemonSocketIdentity` asserted
  `info.Sys().(*unix.Stat_t)`, but `golang.org/x/sys/unix` v0.47 defines its own
  `Stat_t`, so the assertion never matched and **every** Linux sandbox launch
  failed with `cannot establish app-server socket mount isolation`. It now reads
  `syscall.Stat_t` (Rust #46125 reads the mount id of the opened directory).
  Regression: `TestDaemonSocketIdentityReadsTheOpenedDirectory`.
- `applypatch`: the no-follow walk started at `/`, so on macOS a workspace under
  `/var/folders` was rejected by the `/var` system symlink before the walk ever
  reached the workspace — full-access sessions could not apply any patch there.
  The walk now starts at the resolved workspace root and still rejects every
  link inside it; absolute targets outside the workspace keep the strict walk.
  Regression: `TestNoFollowSymlinksTrustsResolvedWorkspaceRoot`.
- `worktree`: `repositoryRoot` returns the canonical `git rev-parse
  --show-toplevel`, but `Create` compared it with the unresolved working
  directory, so a macOS checkout under a symlinked path reported "working
  directory is outside the repository root". Both sides are now compared after
  `EvalSymlinks`, and the managed root is canonical before
  `git worktree add`, because git records the canonical path and
  `git worktree remove` cannot match a `/var` spelling for a
  `/private/var` registration.
- `appserver`: a brokered launch kept `state=used` in the snapshot command
  metric while Rust `snapshot_metrics.rs` starts observing before provisioning;
  the fallback is now recorded as `state=protected outcome=fallback`.

## Fixtures that assumed the Windows host

- Bundle fingerprint: Rust hashes the platform-encoded relative paths,
  so the Windows and POSIX vectors differ. The POSIX vector was produced with a
  real Rust program on Kali.
- Image generation migration: Windows-captured vectors carry `C:/`
  paths that POSIX drops as relative, and `/tmp` paths Windows rejects.
- Trust keys must not be lowercased outside Windows; gateway
  credentials (#58219) need `credentials_store = "file"` when the host has no OS
  keyring; managed networking is a Windows-only path.
- `appserver` fixtures compared raw `t.TempDir()` spellings against the
  canonical paths discovery reports (skills, instruction sources, plugin
  caches, disabled-skill paths, executor skill locators). macOS reports its
  temporary directory through `/var`, so the fixtures now canonicalize the temp
  directory, the way Rust's own no-follow fixtures do.
- `tool`: the PTY child reports the resolved `/private/var` cwd, the PATH dedup
  assertion cannot demand the leading position after macOS `path_helper`
  rewrote PATH, and the hook detach check used `ps -o sid=`, which BSD `ps`
  does not have — it now asserts the portable half (pid == pgid).
- `sandbox/linuxsandbox`: the legacy Landlock test still expected the WSL
  interop message that #45984 replaced with the bubblewrap requirement, and the
  glob scanner probe called `env` with a PATH that only held the scanner
  directory; both are now host-honest.
- `app`: `selected_store` names the platform keyring backend
  (`direct_keyring` on Linux/macOS), a direct Unix socket path never verifies
  without the daemon alias, `sun_path` is 104 bytes on Darwin so socket
  fixtures live under a short directory, macOS has a Seatbelt sandbox backend,
  and a marketplace root is published canonically.

## Host limitations recorded, not worked around

- Apple git 2.32 (macOS default) has no `git worktree list --porcelain -z`.
  Rust parses the same command, so the Go manager keeps parity and the listing
  tests skip when the switch is missing.
- macOS `sun_path` is 104 bytes; socket fixtures now use a short temp root
  instead of relying on long `/var/folders` names.
