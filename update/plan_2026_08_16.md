## Committed in this batch

1. #38767 Forward workload identity context during token exchange
   - `auth` reads `OPENAI_WORKLOAD_IDENTITY_CONTEXT`, forwards it unchanged as
     the `workload_identity_context` exchange field, and includes it in the
     workload identity session fingerprint so sessions with different values
     cannot share an exchange; `envutil` scrubs the variable from
     model-reachable child environments (Rust `NON_INHERITABLE_ENV_VARS`).
2. #38795 Add storage diagnostics to `codex doctor`
   - New `system.disk` check reports available space for `CODEX_HOME` and the
     active worktree (warning below 5 GiB, failure below 1 GiB, measured via
     `unix.Statfs` / `windows.GetDiskFreeSpaceEx`). New `git.worktree.dev_drive`
     check (Windows) reports whether the active Git worktree is on a trusted
     Dev Drive (IOCTL persistent-volume-state flags) with remediation.
     Feedback doctor-report workspace anchoring is N/A: Go has no feedback
     doctor attachment.
3. #38800 Route executor policy audits through log-only telemetry
   - Forwarded `codex.network_proxy.policy_decision` events carry
     `target=codex_otel.log_only`; the state `LogDBHandler` excludes that
     target from the persistent log while standard logging still receives it.
4. #38827 Add endpoint protection checks to `codex doctor`
   - New `security.endpoint` check detects CrowdStrike Falcon, BeyondTrust
     Privilege Management, Microsoft Defender and SentinelOne (Windows
     `sc.exe query`) plus Jamf Protect (macOS `systemextensionsctl list`),
     with product-specific exclusion remediation and
     complete/partial/unavailable inspection states.
5. #38840 Identify Mac mini hosts in remote control handshakes
   - Remote-control WebSocket handshakes send `x-codex-host-device-kind:
     mac_mini` on macOS when `system_profiler` reports a machine name of
     exactly `Mac mini` (2 s timeout, cached successful detection, header
     omitted on other platforms/failures).

for dedicated follow-up batches:

   - Go's `codex exec` stays on Rust's legacy fallback; enabling paginated

     with the appserver (`sessionItemForAppToolCall`) so every exec item

   - Go TUI has no connector directory scope-generation invalidation,

   - Go's bubbletea startup flow has no provisional-composer loading-message
     surface equivalent to Rust's `StartupDraft` session-action status.
4. #38830 Isolate external editor buffers from sandbox-writable paths
   - Go's tea external editor writes composer buffers via `os.CreateTemp` to
     the system temp dir; protecting them under a sandbox-non-writable
     `codex_home/editor` directory requires threading the filesystem policy
     into the tea model.
