## `#49856` Daybreak selection in `codex exec`

`daybreak_enabled` is a validated optional top-level config value, carried into
non-interactive/local thread starts. App-server resolves the per-turn cyber
access program from explicit selection or the inherited core value and
propagates it to responses, compaction, and subagents.

## `#49880` Permission grants bound to the originating turn

`state.TurnState` owns granted permission maps per environment independently of
`SessionState`. Guardian review and sandbox retries resolve the reviewed turn's
own profile, so one turn's grant does not become session-wide review authority.

## `#49972` Shared exec-server output byte buffers

Output chunks retain `[]byte` buffers, while JSON serialization preserves the
base64 wire contract. The focused chunk-sharing regression passes; the known
Windows PowerShell fallback read test remains an unrelated baseline failure.

## `#50050` Step-scoped plugin and skill snapshots

`runtimeStepCapabilitySnapshot` freezes ready roots, disabled plugin IDs, plugin
capabilities, and plugin skill roots for one sampling step. Catalogs, executor
skills, root attribution, and discovery read that snapshot; a new environment
request takes effect only on the next captured step.

## `#50083` Paginated attachment reverse lookup

The app-server owner lookup performs the reverse query by attachment type and
identity key with archive filtering, stable ordering, limit, next cursor, and
cursor validation at the persisted-session metadata boundary.
