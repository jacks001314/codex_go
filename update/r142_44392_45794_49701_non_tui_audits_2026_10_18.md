# Non-TUI audits: API-key model discovery, image file IDs, SQLite recovery

## `#44392` OpenAI API-key model discovery

Go exposes `api_key_model_discovery`, keeps inference URLs separate from live
model discovery, treats a discovered API-key catalog as authoritative, and
requires a restart for live setting changes. Model and feature tests pass.

## `#45794` Image references by file ID

File-backed image references flow through user inputs, session history, tool
outputs, output truncation, dynamic tools, and image-generation windows without
being mistaken for inline URLs. Utils and turn tests pass.

## `#49701` SQLite corruption recovery

Go runs quick-check validation during state startup, detects corruption, creates
recovery backups, and shares one validation manager across SQLite clones. State
recovery tests pass.
