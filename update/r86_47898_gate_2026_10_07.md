## 1) Rust ↔ Go 对照

Rust 的 `NetworkProxyConfig.allow_local_binding` 与 `EnvironmentNetworkPolicy.allow_local_binding` **两侧都是 `Option<bool>`**；
`apply_to` 的组合规则由「AND 已解析值」改为：

```rust
config.allow_local_binding = match (config.allow_local_binding, self.allow_local_binding) {
    (Some(controller), Some(owner)) => Some(controller && owner),
    (controller, owner) => controller.or(owner),     // 任一侧省略 ⇒ 用另一侧
};
```

并把 `local_binding_policy.resolve(&config)`（`LocalBindingPolicy::DefaultFalse`：`unwrap_or(config.enabled && false)`）
从 `apply_to` **之前**移到**之后**（`network_proxy_spec.rs:287`、`proxy.rs`）。

Go 现状（修复前）= 两侧都是普通 `bool`，`&&` 把「省略」当 `false`：

| 位置 | 修复前 | 修复后 |
|---|---|---|
| `network/network.go:39` `Config.AllowLocalBinding` | `bool` | `*bool`（nil = 省略） |
| `network/network.go:155` `EnvironmentNetworkPolicy.AllowLocalBinding` | `bool`（无 tag） | `*bool \`json:"allowLocalBinding"\`` |
| `network/network.go:169` `EnvironmentNetworkPolicyFromConfig` | `config.AllowLocalBinding` | `cloneBool(config.AllowLocalBinding)`（保留省略） |
| `network/network.go:222` `ApplyTo` | `config.AllowLocalBinding && p.AllowLocalBinding` | Rust 同款三分支（省略继承 / 任一侧显式 false 即拒 / 两侧显式则 AND） |
| `network/network.go:388` `ValidateAgainstConstraints` | `config.AllowLocalBinding != *constraints.…` | `boolPointerValue(config.AllowLocalBinding) != *constraints.…`（行为不变，nil→false） |
| `network/network.go:482` `applyRequirements` | `*requirements.AllowLocalBinding` | `cloneBool(requirements.AllowLocalBinding)` |
| `network/network.go` `cloneConfig` | — | 新增 `cloned.AllowLocalBinding = cloneBool(...)` |
| `NewSpecForEnvironment`（组合后） | 无解析 | `nil ⇒ false`（`LocalBindingPolicy::DefaultFalse`；Go 无 RequireTrue） |

Go 无 `LocalBindingPolicy`/`RequireTrue` 概念（grep 0 命中），故省略解析恒为 `false`，
与 Rust `DefaultFalse` 行为一致；`controller: Option<&Self>`（Rust 可无 controller）在 Go 是既有建模差异，**不属本 PR**。

## 2) wire 结构 before / after（队长要求）

探针实测（临时文件，已移除）：
```
omitted policy wire = {"Domains":null,"UnixSockets":null,"AllowUpstreamProxy":false,"DangerouslyAllowAllUnixSockets":false,"allowLocalBinding":null,"ManagedAllowedDomainsOnly":false}
explicit true wire  = {... "allowLocalBinding":true ...}
explicit false wire = {... "allowLocalBinding":false ...}
decode {}                      -> nil? true      # 缺省 ⇒ nil（继承）
decode {"allowLocalBinding":null} -> nil? true   # null ⇒ nil（继承）
```

| | before | after |
|---|---|---|
| 字段类型 | `bool` | `*bool` |
| 键名 | `AllowLocalBinding`（无 tag） | `allowLocalBinding`（对齐 Rust camelCase） |
| 省略时 | `false`（**与显式 false 不可区分**） | `null`（= Rust `Option::None`） |
| 显式 false | `false` | `false` |

Rust 侧 `allow_local_binding: Option<bool>` 无 `skip_serializing_if` ⇒ 省略序列化为 `null`，省略/`null` 反序列化均为 `None`。
Go 改后与之**语义一致**（缺省与 null 都 ⇒ nil ⇒ 继承）。
⚠️ 本结构体其余字段仍是无 tag 的 PascalCase（`Domains`/`AllowUpstreamProxy`/…）——**既有漂移**，不在本 PR 范围，未动。
（`EnvironmentNetworkPolicy` 在 Go 生产代码中**从不** marshal/unmarshal：grep `json.` in `network/` 仅命中其它类型，故键名调整无生产消费风险。）
