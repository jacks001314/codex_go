# Rust #43903: Windows deny-read glob scan planning

Upstream commit: `4fd2c460dd3e02495c1d0aae8bce4ccbd59915a9`

## Result

Equivalent shared implementation.

- `sandbox.WindowsDenyReadGlobScanForPattern` performs only string inspection:
  it finds the first glob metacharacter, keeps the deepest literal directory
  (including drive roots and the leading separator), records the glob suffix,
  and computes the traversal depth.
- A recursive `**` component inherits the configured maximum depth; a
  non-recursive suffix is capped at its component count.
- `sandbox/windowssandbox.GlobScanPlanForPattern` consumes the shared helper for
  native ACL expansion, so policy validation and ACL planning use the same
  bounds without filesystem access.
