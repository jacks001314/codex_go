# Round 1193: refresh credentials for disabled sandbox accounts (2026-10-31)

Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

## Gap

Rust #42375 (`is_refreshable_windows_error`) treats `ERROR_ACCOUNT_DISABLED`
(1311) like `ERROR_LOGON_FAILURE` and `ERROR_NO_SUCH_LOGON_SESSION`: uninstall
or an interrupted cleanup can disable the sandbox accounts, and a runner logon
must refresh the stored credentials instead of surfacing the native failure.
Go classified only the other two codes, so a disabled account failed the logon.

## Change

- `sandbox/windowssandbox/elevated/runner_client.go`: add
  `errorAccountDisabled = 1311` and include it in
  `isRefreshableWindowsError`, so `RetryRunnerSpawnOnce` refreshes credentials
  and retries the logon once.
