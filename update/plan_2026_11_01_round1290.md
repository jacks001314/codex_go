## Advanced this round

Rust has two host transports that differ only by launch arguments
(`code-mode-host/src/transport.rs`):

```rust
pub const DEFAULT_LISTEN_URL: &str = "stdio";
match parse_listen_url(listen_url)? {
    ListenTransport::Stdio => crate::run_stdio().await,
    ListenTransport::GrpcStdio => crate::grpc_stdio::run(host).await,
    ListenTransport::Grpc(bind_address) =>
        grpc_transport::run_tcp_listener(bind_address, host).await,
}
```

and `HostConnection::spawn` in `core/src/code_mode_host.rs` always asks for the
gRPC one:

```rust
command
    .args(["--listen", "grpc+stdio://"])
```

Go had the client half (`codemode.GrpcProcessProvider`) and a gRPC stdio server
(`codemode.RunGrpcStdioHost`), but the two were never joined:

- `cmd/codex-code-mode-host` parsed `--listen` and then ignored it, always
  running the framed-JSON host;
- `spawnGrpcStdioProcess` launched the host with no arguments, so the host
  served framed JSON while the client dialled gRPC on the same pipes. Enabling
  `code_mode_host_grpc` against a Go install therefore hung until the 30 s
  handshake timeout (the provider tests masked it by selecting the host mode
  through a test-only environment variable instead of the real argv);
- Rust's `grpc://IP:PORT` TCP transport had no Go entry point at all.

## What changed

- `cmd/codex-code-mode-host/main.go`: `selectListenTransport` mirrors Rust's
  `parse_listen_url` (including both error messages), and `runCLI` dispatches to
  the framed-JSON host, the gRPC stdio host, or the new TCP host.
- `codemode/grpc_stdio_host.go`: `newGrpcHostServer` is shared by the stdio and
  TCP hosts; `RunGrpcTCPHost`/`ServeGrpcTCPHost` serve the same gRPC host on a
  listener and stop when the context is cancelled.
- `codemode/grpc_process_provider.go`: spawn with `--listen grpc+stdio://`, as
  Rust's `HostConnection::spawn` does.
- `codemode/process_provider_test.go`: the helper process now runs the real
  `--listen` dispatch (mode `cli`) instead of a test-only switch, so the
  provider tests fail if the argument is lost.
- `cmd/codex-code-mode-host/main_test.go`: listen-URL table plus the
  unsupported-URL exit path.
- `codemode/grpc_tcp_host_like_rust_test.go`: end-to-end exec over the TCP
  transport and shutdown on cancellation.
