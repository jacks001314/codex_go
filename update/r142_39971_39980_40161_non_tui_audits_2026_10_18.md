# Non-TUI audits: elevated setup, remote network policy, exec thread source

## `#39971` Elevated Windows sandbox setup

Go's elevated setup uses synchronous `ShellExecuteExW` activation
(`SEE_MASK_NOASYNC`) because setup runs without a Windows message loop.
Windows sandbox setup tests pass.

## `#39980` Environment network policies for remote execution

Go resolves owner/attachment network policy per selected environment, preserves
inherited denials, applies the policy to the execution-scoped proxy, and
requires the proxy wire where appropriate. Network policy tests pass.

## `#40161` Exec caller thread classification

Go accepts a caller-supplied `--thread-source` for new/forked exec threads,
trims it, and still forces `subagent` for subagent context. Added a focused
regression covering default, custom, trimmed, and subagent-override cases.
