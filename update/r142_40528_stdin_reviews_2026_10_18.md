# Rust #40528: terminal input in approval reviews

Upstream commit: `9c9675d3d038d9e827875c6bdceb2c6d68439dfc`

## Result

Core, protocol, and analytics portions implemented; TUI rendering stays with
the TUI lane.

- `ExecApprovalKind` distinguishes `command` from `writeStdin`; absent kinds
  serialize/default as `command` for older peers.
- A stdin approval now targets the existing parent command item, sends the
  write call id as `approvalId`, and keeps the `write_stdin --session-id N`
  command text for user approvals.
- Guardian review actions serialize
  `{type: "writeStdin", approvalId, processId, stdin, cwd}`; the review targets
  the parent item so the command item lifecycle is unchanged.
- Analytics classify stdin reviews as `write_stdin`, not
  `command_execution`.
- TUI progress/denial/timeout/retry rendering is part of the TUI lane.
