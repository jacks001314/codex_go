## Findings

- #47968 was a real gap. `daemonSocketIdentity` now records the opened socket
  directory's filesystem with `fstatfs`; mountinfo parsing keeps the fstype after
  the optional-fields separator, and a device mismatch is accepted only when the
  descriptor is Btrfs and the selected mount also reports `btrfs`. Alias checks
  use both the descriptor's `st_dev` and the selected mount's superblock device.
  Go continues to reject exposed aliases instead of masking them, as it already
  did for #46125.
- #44138 was a real gap in the compressor: `compressionSkippedBusy` existed but
  was never produced. Compression now takes the shared `session.WriterLock`
  after encoding/verification and before the final state check and publication,
  returns `skipped_busy` for an active writer, and compresses after release.
  The remaining recorder background-ownership and metadata-patch conflict paths
  from the same upstream commit are not ported, so this stays `partial`.
- #47663 is already satisfied: `httpClientForConfig` and
  `policyHTTPClientForConfig` wrap the transport with the managed policy, so
  redirects are checked hop by hop and proxy/custom-CA clients stay bound.
- #47742 is already satisfied: history-notes and image-generation both receive
  the policy-bound `model.HTTPDoer` from `httpClientForConfig`.
- #43913 adds tracing spans only; Go tracehook instruments exec-server process
  lifecycle and these paths have no context to attach an equivalent span.
- #44183 assumes thread startup joins MCP discovery while holding an
  uncommitted writer. Go starts MCP prewarm asynchronously and
  `LiveThreadRetention` discards the writer on failure, so the leak has no Go
  equivalent.
- GitHub has no open PR: only PR #1 (`sync1013`) exists and is already merged;
  `origin/main` equals local `main` at `fefb7c65`. The parallel usealign agent's
  changes are still uncommitted in the shared worktree and were not touched.
