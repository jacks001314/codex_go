feeds `state.RenderGuardianTranscript`, bounded selection, host attribution,
compaction-summary filtering, encrypted native messages, JSON/line rendering,

## `#41919` Guardian REPL policy from model metadata

Auto-review Node REPL policy resolves from model metadata with bundled fallback
and explicit-empty suppression. The session runner invalidates cached reviewer
history when the effective policy changes while keeping unchanged policies
reusable.

## `#42033` Guardian feedback diagnostics

Feedback selection is bounded to eight tree rollouts, keeps the reported
thread, prioritizes descendants with retained failed reviews, and records a
bounded feedback-thread index with omitted IDs and discarded-review accounting.

## `#42326` Windows control socket rendezvous

The control-socket path prepares a protected current-user-only directory,
rejects broad existing directories and junction/volume-root targets, and pins
the validated directory against replacement while dialing.

## `#42404` Voice helper frame reader

frames across split or coalesced pipe chunks, retaining late frames for the
next exchange.
