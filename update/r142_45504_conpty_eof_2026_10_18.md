# #45504 ConPTY output closes after the last console client exits

## Upstream change

After a successful ConPTY spawn, the pseudoconsole creation handles no longer
need to stay open. Releasing them lets the output reader observe EOF when the
last attached client exits, without forcing the caller to close the PTY.

## Go status

Complete by equivalent implementation.

`sandbox/windowssandbox/conpty` drops the creation handles after a client has
attached, while the exec-server TTY session uses the same lifecycle. The
Windows regression `TestExecServerTTYOutputReachesEOFWithoutClosingThePTY`
verifies the reader reaches EOF after the child exits while the PTY remains
open.

## Verification

- `go test ./execserver -run 'TestExecServerTTYOutputReachesEOFWithoutClosingThePTY' -count=1 -v`
