### 0.1 gofmt 门禁的环境事实（重要，影响所有车道）

本 worktree 由 `git worktree add` 新建，而本机 Git **系统级** 配置 `core.autocrlf=true`

因此新 checkout 的全部 `.go` 文件在磁盘上是 CRLF。`gofmt` 会把 CRLF→LF 视为需要格式化，
所以 **原始 `gofmt -l .` 在本 worktree 输出 3479 行（= 每个 .go 文件），这是换行符产物，不是格式化缺陷**。

证据（把 worktree 的 `.go` 全部按 CRLF→LF 归一化到临时镜像后跑 gofmt）：

```

$ cd $env:TEMP\r90c\lfmirror; gofmt -l . | Measure-Object        # 32
```

基线对照：同样把**主工作区** `D:\qax\reagent\dev\codex_go`（未被本车道改动）全量 `.go` 归一化后


`mermaid/mermaid_test.go` 三个改动文件在归一化镜像中 **都不在 gofmt -l 清单里**（即 gofmt-clean）。
