# Round 1175 audit plan (2026-10-31)

Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

This round closes #43715 ("Enable user verification for the bundled TUI on
supported devices"). Rust only replaced the host activation probe (the previous
round already ported the eligibility projection), so the audit focused on the
ownership rules the commit's new tests exercise.

## Rust behaviour

- `app-server/src/user_verification.rs` now uses `native::device_supported`; the
  initialize processor projects `userVerification` only for an opted-in
  in-process `codex-tui` (or stdio `Codex Desktop`) whose probe reports support.
- `app-server/src/outgoing_message.rs`: a verification ceremony records
  `verification_owner` and the auth revision it started under. Only that
  connection may answer; any other response is dropped. Thread replay filters
  verification requests out.
- `app-server/src/user_verification_auth.rs`: closing a transport removes its
  verification ownership immediately, before unrelated RPC handlers drain, and
  an auth watchdog cancels ceremonies whose revision changed.

## Go gaps found

- `ServerRequestBroker.ResolveFromConnection` only constrained managed
  `humanCommand` checkpoints, so any connection could answer a targeted
  `userVerification` elicitation.
- Pending verification requests were replayed to every subscriber of a thread.
- `RuntimeRouter.ConnectionClosed` ran after the stdio RPC drain, and no code
  canceled ceremonies on auth changes.

## Change

- The broker marks native verification requests, pins them to the owning
  connection and the router's auth revision, and drops foreign or stale
  responses.
- `CancelVerificationPending` / `CancelStaleVerificationPending` fail the
  pending waiter immediately; the router wires them to connection close and to
  `afterAuthChanged`.
- `releaseUserVerificationConnection` clears ownership, cancels owned
  ceremonies and re-syncs the MCP capability; stdio and websocket call it as
  soon as the transport closes, before draining handlers.
- Thread replay skips verification requests.
