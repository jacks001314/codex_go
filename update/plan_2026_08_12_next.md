### N/A for Go (documented)

- **Notify running turn watchers only on count changes** (`16fbfe5574`,
  #38170): Rust `ThreadWatchManager` publishes the running-turn count with
  `watch::Sender::send_if_modified` so unrelated state updates (e.g., a
  permission request during a turn) do not wake count subscribers. Go
  `ThreadStatusManager.RunningTurnCount()` is a polling getter with no watch or
  subscription channel — there are no count subscribers to wake; nothing to
  change.
- **Resolve subagent analytics connections lazily** (`3fe19fcd81`, #38165):
  Rust `AnalyticsReducer` walks the parent-thread chain
  (`thread_connection_id`) when a subagent's connection was not captured
  directly, because subagent-start facts can arrive before the parent's
  connection context. Go emits analytics synchronously with `connectionID`
  threaded through the turn runtime (`runTurnRuntime`/`runReviewRuntime`) and
  has no decoupled analytics reducer with this parent-connection race — already
  equivalent.
