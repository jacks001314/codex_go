## `#46512` Capture Guardian review checkpoints from live context

Go 的 Guardian reviewer 没有 Rust 的 forkable checkpoint / storage reload 路径：

- `guardianSessionRunner` 在内存中维护 `previous`/`seeded` response ID、transcript
  admission cursor、policy、completed review count 与 evidence cursor。
- review attempt 直接使用 live request/history，从不 flush 后重新从 rollout
  storage 读取 transcript 来构造 checkpoint。
- Go 没有 `guardian_fork_history` 或 `world_state_checkpoint` 类型的等价载体。

因此该提交要移除的“提交 review 时 flush/reload storage”在 Go 中不存在；
live-context 行为已由现有内存 session 模型满足。

## `#44284` Windows system config namespace telemetry

Go 明确没有 Windows system config namespace：

- `config/local_layers.go` 记录 Go 不支持
  `%ProgramData%\OpenAI\Codex\config.toml`、系统 requirements、磁盘 MDM/企业
  managed layer 或 macOS managed admin requirements。
- 因而不存在 `windows_codex_system_dir()`、system config 目录或该 namespace
  的 owner/ACL 探测对象；host 运行时传入的等价配置层也不走该路径。
