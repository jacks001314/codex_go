# Round 1195: suppress incremental model change announcements (2026-10-31)

Target: Rust `main` at `67f0994b532b8740f14b5b738af7b7b2a915b1d6` (#58405).

## Gap

Rust #58405 adds the default-off `suppress_model_change_announcements` feature.
With it enabled, an incremental context window omits the model ID announcement
after a model switch while still sending changed base instructions and tool
definitions, and the model snapshot advances even when a switch emits no update.

## Change

- `features/features.go`: register `suppress_model_change_announcements` as a
  stable, default-off feature.
- `session/top_level_tools.go`: `ModelInstructionsUpdate` takes the flag,
  computes `announceModel = modelChanged && !suppress`, and returns a third
  boolean that reports when the caller must persist the model snapshot. A
  suppressed switch returns no update but still advances the snapshot.
- `appserver/incremental_tools.go`: resolve the flag from the effective config
  (`suppressModelChangeAnnouncements`) and persist the base-instruction snapshot
  whenever `ModelInstructionsUpdate` reports advancement, instead of only when
  the instruction hash changed.
