## Upstream audit (42 commits)

### Implemented in this batch (Go code + tests)

1. **Allow empty input to start a turn** (`52d9218424`, #38084)
   - Rust now permits immediate user-message admission with empty items: the
     turn starts, proceeds with generated environment context, and emits no
     user-message item. Persisted admission still rejects empty input.
   - Go: `turn/api.go` `TurnService.Steer` no longer rejects empty input; the
     app-server `turn/steer` path proceeds without creating a session item or
     enqueueing input items. Persisted/thread-store paths still require input.
2. **Disable storage for Azure Responses requests** (`46c3268542`, #38060)
   - Rust sets `store: false` for every Responses request and removes the
     provider-specific Azure storage check.
   - Go: `appserver/agent_runtime.go` no longer derives `Store` from
     `IsAzureResponsesProvider`; all providers send `store: false`.
3. **Use `ReviewDecision` for MCP tool approvals** (`67afc79674`, #38081)
   - Rust adds `ReviewDecision::ApprovedMcpPolicyAmendment`
     (`approved_mcp_policy_amendment`) and routes MCP accept/for-session/
     remember decisions through the shared decision type, rejecting the MCP
     policy amendment on command/shell/network approval paths.
   - Go: `appserver` `ReviewDecision` protocol enum gains the new value; MCP
     approval parsing maps remember-to-the-policy amendment through the shared
     decision and non-MCP approval paths reject it.
4. **MCP OAuth per-login client registration selection** (`6dc3ac8721` #38052,
   `4c89139da9` #38089)
   - Rust adds optional `clientRegistration` (`auto` default, `cimd`, `dcr`) to
     `mcpServer/oauth/login` and the `codex mcp` CLI.
   - Go: `MCPServerOauthLoginParams` gains `clientRegistration`; `auto` and
     `dcr` select the existing DCR flow, `cimd` is explicitly rejected with a
     clear error because the Go OAuth client has no CIMD client-metadata flow
     yet (tracked as partial; wire format matches Rust).
5. **Propagate custom CA settings to local MCP servers** (`b2543af02b`, #38040)
   - Rust forwards the 11 custom CA env keys to local stdio MCP servers,
     converting inherited non-empty paths to absolute paths, with explicit MCP
     environment overrides taking precedence.
   - Go: `mcp/stdio_client.go` launch environment applies the same CA env
     forwarding (absolute path conversion, case-insensitive dedupe on Windows,
     explicit overrides win).
6. **Allow nested Git repositories in the Windows sandbox** (`7c47952f7c`,
   #38080)
   - Rust injects both the worktree root and its `/*` wildcard into Git
     `safe.directory`.
   - Go: `sandbox/windowssandbox/sandbox_utils.go` `InjectGitSafeDirectory`
     emits both entries.
7. **Propagate MCP elicitation event delivery failures** (`e20616d265`, #38035)
   - Rust returns a contextual error when the MCP elicitation event channel is
     closed, dropping the pending-request guard immediately.
   - Go: `appserver` `ServerRequestBroker` pending requests are resolved (error)
     when the sink disappears; regression test covers closed receiver.
8. **Include auto-review state in turn metadata** (`f2a6f2585c`, #38046)
   - Rust adds reserved `auto_review_enabled` metadata key derived from
     approval-policy routing for regular and review turns.
   - Go: `turn` `MetadataState` gains `auto_review_enabled` (reserved key in
     `codexapi`), populated from the effective approval-policy/guardian routing.
