  `glob_pattern` deny-read entry, so no unreadable-glob regex policy existed and

- Go now mirrors Rust's `build_seatbelt_unreadable_glob_policy`: restricted deny
  globs resolve against the sandbox cwd, translate to anchored
  `(deny file-read* (regex ...))` / `(deny file-write* (regex ...))` rules, and
  add `file-write-unlink` denies for each ancestor directory. The translation
  matches `seatbelt_regex_for_glob` (globstar, component `*`/`?`, character
  classes, brace alternation, backslash escapes, subtree suffix for literals).
- `canonicalize_glob_static_prefix_for_sandbox` adds a second, symlink-resolved
  pattern so denies also cover the canonical target of the static prefix.
- #47920's refinement is included: a root-anchored recursive literal basename
  (`/**/.env`) skips ancestor-unlink denies and widens its regex to
  `(/.*)?$` so descendants of a matching directory stay protected; scoped,
  multi-component, and non-literal patterns keep ancestor protection.
- Glob denies are emitted after every allowance so Seatbelt cannot reopen them,
  and before the protected-ancestor/fcntl denies, matching Rust's section order.
