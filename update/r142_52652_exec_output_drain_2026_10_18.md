# Rust #52652: bound local exec output draining after process exit

Upstream commit: `89c8759d8c497b30629a2d67a51c163aa9ed3c44`

## Result

Equivalent implementation was already present.

- Direct local unified execution starts a bounded post-exit output drain.
  `localUnifiedExecOutputDrainGrace` caps the reader wait, then closes inherited
  readers so a descendant holding stdout/stderr cannot delay completion.
- Output already observed before the bound is retained in the transcript,
  events, and result.
- Exec-server-backed execution keeps waiting for `process/closed` after an
  exit event, matching Rust's remote policy and retaining buffered or delayed
  output.
- Go does not have a separate local exec-server process policy because direct
  local execution uses the in-process reader path.
