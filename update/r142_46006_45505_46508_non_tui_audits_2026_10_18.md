# Non-TUI audits: clock recovery, unified-exec tracing, auth catalog refresh

## `#46006` Clock failures after recovery

Go supports `nonfatal_clock_read_errors`, records the last clock failure per
thread, emits the current-time-unavailable context fragment, and lets a stalled
external clock fail the turn before inference. While verifying this item I found
that the server-request broker dropped the client error detail. It now propagates
a bounded ordinary-request message (including `currentTime/read`) while
credential and attestation methods continue to suppress client-supplied text.

## `#45505` Unified-exec lifecycle tracing

Go opens unified-exec session/output/write-stdin spans and records exec command
mode and termination details through the existing span sink. The dedicated
unified-exec span tests pass.

## `#46508` Model-catalog refresh after auth changes

`model/lazy_models.go` and the models endpoint record the catalog identity and
perform a best-effort refresh when the in-memory catalog belongs to a previous
auth identity. Model catalog tests pass.
