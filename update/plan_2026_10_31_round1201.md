# Round 1201: host non-consuming input activity waits (2026-10-31)

Target: Rust main at 67f0994b532b8740f14b5b738af7b7b2a915b1d6 (#58411).

## 58411

Rust exposes `CodexThread::wait_for_input_activity` and exports
`InputWaitOutcome` through core and core-api so host-owned tools can wait for
agent messages or steering input exactly like native `wait_agent`, even when
native multi-agent support is disabled. `wait_agent` now shares the same
`thread_input` helpers, `InputQueueActivity` orders `Mailbox < Steer`, and
`TurnInputQueue::notified_activity` replaces `has_pending_injection`.

Go mirrors it in two layers:

- `turn.InputWaitOutcome` (`TimedOut`, `MailboxActivity`, `Steered`),
  `SteerMailbox.SubscribeActivity` (subscribe then report the named turn's
  pending activity under one lock), `SteerMailbox.LastActivityFor` (the value
  of the most recent notifying write, tagged with its queue key so another
  thread's write cannot wake this wait), and
  `SteerMailbox.WaitForInputActivity`. The wait is non-consuming, observes
  thread-wide activity so ending or replacing the named turn does not end it,
  reports `Steered` for user input, function-call output and notifying
  injections, reports `MailboxActivity` for agent mail, and maps cancellation
  and deadline expiry to `TimedOut`.
- `RuntimeRouter.WaitForInputActivity` mirrors `CodexThread::wait_for_input_activity`
  for hosts: it combines the mailbox wait with the router's agent activity
  sources (queued agent messages and `wait_agent` notifications), peeks at them
  without consuming, and prefers steering when both kinds are pending.
  `publishAgentActivity`/`subscribeAgentActivity` add a non-consuming wake
  channel for those writes.

`wait_agent` itself keeps its existing predicate set: `WatchSteer` already
subscribes before its first check and only wakes for steering input, and the
agent activity channel already carries mailbox notifications, so the native
path needs no behavior change.

Coverage: `turn/steer_mailbox_input_wait_like_rust_test.go` (pending steer and
mail, inactive wake, replacement-turn wake, other-thread isolation, timeout,
cancellation, independent observers, non-consuming drains) and
`appserver/host_input_wait_like_rust_test.go` (queued and live agent mail,
replacement-turn steering, steering precedence, timeout, cancellation).
