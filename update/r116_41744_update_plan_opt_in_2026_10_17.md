# Round 116 · #41744 update_plan prompt guidance follows the opt-in tool

Rust source: `a9519cbcdd`.

## Landed

- Added `prompt.WithoutUpdatePlanInstructions`, the Go port of Rust's
  `without_update_plan_instructions` line filter. It removes the bundled
  `## Planning` (only when it contains `update_plan` guidance),
  ``## `update_plan` ``, `## Plan tool`, and
  `## Plan Mode vs update_plan tool` sections, the `Progress visibility:`
  goal block, and the two checklist list-item forms, while leaving unrelated
  planning text untouched.
- Base instructions: `appTurnConfig` and thread-start instruction sources strip
  the guidance only when the instructions are the bundled prompt (no
  catalog-owned `InstructionsTemplate`) and `tools.update_plan.enabled` is
  false. Custom `instructions`/`model_instructions_file` and catalog templates
  are preserved verbatim.
- Collaboration mode: catalog mode instructions are filtered when the tool is
  disabled, and the world-state snapshot hashes the filtered text (custom
  client-supplied collaboration instructions are preserved).
- Multi-agent V2 usage hints: `OmitUpdatePlanInstructions` filters the resolved
  role text when the tool is disabled and no catalog role text owns it.
- Goal continuation: `prompt.ContinuationWithUpdatePlan` omits the
  `Progress visibility:` planning paragraph while preserving the objective and
  every other instruction; the app-server continuation path resolves the
  thread's effective setting.

Tool registration was already opt-in in Go (`Config.UpdatePlanEnabled` defaults
to false); this change aligns the bundled prompt guidance with that state.
