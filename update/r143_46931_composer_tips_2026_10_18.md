# `#46931` fullscreen composer-gap tips

- Rust 依据：`57567b8d9e5a158ddce2a8bb5f75ac455b1e9b83`。
- 新增 `composerTipState`：session seed + user turn count 决定稳定选择，
  重绘不会跳变，跨 turn 会变化。
- 使用 `ResolvedTooltips` 解析 `{key:context.action}`，Markdown 渲染后只接受
  单行且不超过 gap 宽度的 tip；OSC 8 链接保留。
- 优先级：usage notice / warning / interaction > tip；tip 仅在 fullscreen、
  `show_tooltips`、空 composer、idle、following、无 modal/popup/selection/
  backtrack/backend banner 时显示。
- Ctrl-click composer-gap footer 行会解析 OSC 8 链接的显示列范围（裸 URL 作为
  fallback），通过 app 的 URL opener 打开；失败时写入 notice。Bubble Tea v1
  没有 Super 修饰键，Super-click 无 carrier。
- `Options.StartupAnnouncement` 可注入 announcement；首个 user turn 前优先
  展示，turn 开始后永久 dismiss，`/clear` 或历史清空不会恢复。

剩余：

- app 侧 announcement fetch/cache：Go 目前只有 TOML 解析，没有启动时异步获取
  并注入 `StartupAnnouncement` 的 host 路径。

验证：

- `go test ./tui -run 'OSC8LinksInLine' -count=1`
- `go test ./tui/tea -run 'ComposerTips|ComposerGapCtrlClick|WarningsFooter' -count=1`
- `go test ./tui/... -count=1`
- `go vet ./tui ./tui/tea ./app`
