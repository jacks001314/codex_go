# Non-TUI audits: AWS network policy, remote-control ownership, direct tool metadata

## `#47408` AWS auth and telemetry network policy

Go checks the signing destination before loading credentials, rejects a
caller-supplied credential exporter without unrestricted application policy,
routes SDK credential/region requests through the policy-aware client, and
cancels revoked fetches. AWS auth tests pass.

## `#44341` Remote-control auth ownership

Live relay connections retire when their authentication owner changes; a
replacement session gets fresh client/replay/enrollment state, and a preference
write admitted by retirement keeps its write permit. Remote-control and
app-server auth-change tests pass.

## `#45185` Direct tool-call metadata binding

Direct invocation metadata is bound to its own output, nested Code Mode
captures are separated from direct calls, reused IDs are not presented as fresh
evidence, and prepared direct calls use the pending reservation. Turn metadata
tests pass.
