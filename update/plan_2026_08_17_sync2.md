### #38894 Add working-directory commands to the TUI

Rust adds `/cd [path]` and `/pwd` (alias `/cwd`) to the TUI:

- `/cd [path]`: change an idle local session's working directory while
  preserving conversation history. Relative paths resolve from the current
  directory; omitting the path selects `~`. The implementation reloads project
  configuration, instructions, permissions, keybindings, file search and hooks
  for the destination, forks the thread at the new cwd (or starts a fresh
  thread when there is no resumable rollout), archives the old thread, and
  attaches the replacement session. Unsafe transitions are rejected: active or
  queued work, background terminals, remote environments, untrusted
  destinations, and incompatible permission profiles.
- `/pwd` (alias `/cwd`): display the current working directory and discard
  asynchronous results left over from the previous directory.

Go's tea TUI had neither command. Implemented:

- `CommandCd`/`CommandPwd` enum values + `/cd`, `/pwd`, `/cwd` parse + slash
  frames with Rust's exact descriptions; `CommandCd` added to
  `CommandSupportsInlineArgs` so `/cd <path>` dispatches directly.
- `/pwd` displays `Current working directory: <cwd>` as an info message
  (Rust wording).
- `/cd` runs the eligibility gates mirroring
  `ChatWidget::can_change_working_directory` (idle primary session, no side
  conversation, no queued submissions, no pending steers, no background
  terminals, not in review mode), resolves relative paths against the current
  cwd and `~/` against the home dir, forks the current thread at the new cwd
  (preserving history), patches the fork's cwd, archives the old thread, and
  attaches the replacement session summary.
- The tea Model gains `WorkingDirectoryChangeFunc` + `OnWorkingDirectoryChange`
  wired by `interactiveWorkingDirectoryChangeHandler` in the interactive app.

Tests mirror the Rust contract: `/pwd` display, `/cd` replacement + history
preservation, running-session rejection, `~` default expansion, and the
interactive handler's fork-at-new-cwd + archive + missing-directory rejection.
