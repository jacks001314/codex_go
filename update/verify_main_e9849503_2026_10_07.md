## §5 结论与告警

**GREEN，可留档。无告警，无「不实」。**

语义提示（非告警，供发布说明引用）：
1. **sync633（#47898）**：`EnvironmentNetworkPolicy` 的 `AllowLocalBinding` 由 `bool` 改为 **`*bool`**（可区分「显式 false」与「未设置」），并保留继承来的 deny —— 这是**类型级 API 变更**，下游若有构造该结构的代码需注意（本批已同步网络测试）。
2. **sync634**：离线 bundled fallback 目录加入 **GPT-6 家族**（`gpt-6.1-sol` / `gpt-6-astra` / `gpt-6-sol` / `gpt-6-luna`，priority 1–4），老家族 priority 后移（`gpt-5.6-sol`→5、`gpt-5.6-terra`→8、`gpt-5.6-luna`→9、另一个 →13）。**默认模型变为 `gpt-6.1-sol`** —— 属**用户可见行为变更**，建议在发布说明点名。
3. **sync635**：Ctrl+Space 在 TUI keymap 运行时归一化（`ctrl-@` → `ctrl-space`）。
4. **sync636**：远程 TUI resume / switch-agent 现在转发**调用者 cwd** 作为 `thread/resume` 的 cwd override（`remoteTUIResumeParams`）；两个 handler 签名因此各加一个 `*cli.RootOptions` 参数（**内部函数签名变更**，非导出 API）。
5. **sync637**：已配置的 keybinding 优先于 transcript 导航（配置键可抢占 PageUp/PageDown），默认键位行为不变。
6. **sync638（#51652）**：`apply_patch` 失败时**保留失败前已提交的 change**（`applyCommitted` 返回 `result, err`），并新增 `codex.agents_md.edit` 计数（`filename` 标签，`path.Base` 而非 `filepath.Base`，大小写不敏感匹配 `agents.md` / `agents.override.md`）。

风险/边界（仅供你判断，非阻塞）：
- sync633 的 `*bool` 是**跨包类型变更**，若其它分支/补丁（如正在排队的批次三产物）也构造 `EnvironmentNetworkPolicy`，需要按新类型重编。
- sync638 的 metrics 走**进程级全局 recorder**（`metrics.Counter`），与 `session_telemetry` 不是同一条通道；若将来 otel 未安装，计数为静默 no-op（与 Go 其它包一致）。
