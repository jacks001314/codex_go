# Round 728: exec runtime, remote exec cleanup, and plugin output audits

本轮复核三个已实现但仍标记为 `audit_pending` 的非 TUI 提交。

## `#52825` exec runtime reset reporting

Rust 依据：`806d9732c974bc8a51b8317c1bd8985544fe627c`。

- `remoteSession.ensureGeneration` 拒绝在 recovery 更换 binding 后继续执行旧调用，
  返回 `execRuntimeResetError`；首次绑定前创建的调用仍可加入首个 generation。
- `existingConnection` 只复用当前 binding；`Terminate` 不重新打开 runtime，因此不会
  掩盖下一次请求需要看到的 reset。

验证：

- `go test ./codemode -run TestRemoteSessionStaleGenerationReportsResetLikeRust -count=1`
- `go test ./codemode -run TestRemoteSessionTerminateDoesNotOpenLikeRust -count=1`

## `#53331` remote exec cleanup with open output streams

Rust 依据：`7e9c061ceb388c67097acac069d6b7f8a60e5011`。

- remote unified-exec 在 `process/exited` 后保留 500ms close wait window，继续收集
  延迟输出，窗口到期执行最终非阻塞 read 并释放 remote session/exit watcher。
- `process/closed` 仍立即完成；`output-open-at-final-poll` 回归覆盖 exit 后延迟输出
  与最终 read 的清理路径。

验证：

- `go test ./tool -run TestUnifiedExecConsumesPushedRemoteEventsAndRecoversReplayLikeRust -count=1`

## `#53109` plugin list broken pipes

Rust 依据：`a07c8ebd57feedc4cf5dfe854c8e9101de54186b`。

- plugin list 的 JSON/table 输出经过 buffered writer；格式化、编码和 flush 错误会
  传播。
- `syscall.EPIPE` 与 `io.ErrClosedPipe` 视为成功，其他输出错误保持失败。

验证：

- `go test ./app -run TestPluginListBrokenPipeLikeRust -count=1`
- `go test ./app -run TestPluginListRemoteCatalogLikeRust -count=1`
- `go test ./app -run TestPluginRemoteAddAndRemoveLikeRust -count=1`
