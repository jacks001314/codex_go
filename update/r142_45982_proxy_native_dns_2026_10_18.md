# #45982 Native DNS resolution for the network proxy on macOS

## Upstream change

macOS proxy TCP connections, including upstream proxy connections, resolve
through the native system resolver so supplemental resolvers and VPN split DNS
are honored. Resolved destinations still pass the existing non-public-address
checks, and unsupported TXT lookups do not fall back to a different resolver.

## Go status

Complete by equivalent implementation.

`network/proxy_lookup_darwin.go` resolves proxy hosts through
`net.Resolver{PreferGo: false}` so the system resolver is used, then falls back
only when the system lookup fails without a context error. Proxy connection
policy still checks every resolved address with the existing non-public-IP
guard.
