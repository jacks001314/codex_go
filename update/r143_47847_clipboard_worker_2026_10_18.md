# `#47847` dedicated clipboard worker

- Rust 依据：`12fd929f724371104a1dea7c14930b078d6b4a18`。
- 新增 session-lived `clipboardWorker`：一次只执行一个阻塞复制任务，busy
  时后续请求直接返回 Busy，不建立 backlog。
- `clipboardSetupTimeout` 默认 5 秒；超时返回
  `clipboard setup timed out; copy abandoned`，worker 仍保持 busy 直到 OS
  调用返回，结果写入 buffered channel 供 late completion 丢弃。
- `/quit`、Ctrl+C、Ctrl+D、`/exit` 路径以 1 秒上限关闭 worker。
- busy 时 PRIMARY publication 只保留最新一条；当前任务结束后先 flush primary，
  再释放 busy；旧 waiter 收到 superseded。
- 测试覆盖 setup timeout、超时后仍 busy、第二次复制被拒，以及 blocking
  task 下的 bounded close。

剩余：

- native clipboard lease/ownership handoff 仍由平台 helper 隐式持有，未建模
  为 Go lease。

- `go test ./tui/... -count=1`
