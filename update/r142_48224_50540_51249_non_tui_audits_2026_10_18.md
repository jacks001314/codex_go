# Non-TUI audits: compact program pairs, Responses Lite catalogs, partial answers

## `#48224` Model/access-program pairs during compaction

The compaction prompt carries the previous turn's model and cyber-access
program pair instead of inheriting the current selection, and attempts without
a fixed program keep the normal fallback. App-server and rollout compaction
tests pass.

## `#50540` Incremental tool catalog updates in Responses Lite

Go records the top-level tool snapshot for a context window and sends the
incremental declaration prefix for Responses Lite, with model-visible
definitions matching the request. Session and turn declaration tests pass.

## `#51249` Partial answers across agent workflows

Commentary and partial-answer completion defer mailbox mail consistently, and
assistant completion boundaries preserve the intended next-request delivery
across agent workflows. Event-map and turn mailbox tests pass.
