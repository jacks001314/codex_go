     `parsedSkillFrontmatter.Model`, `normalizeSkillFrontmatterModel`). Gap = removal.

   - Rust registers `in_app_chat` and `in_app_dictation` as stable, default-enabled
     feature gates exposed in `core/config.schema.json`; requirements can disable them.
   - Go `features/features.go` has `in_app_browser`/`in_app_updates` but no
     `in_app_chat`/`in_app_dictation`. Gap = two stable default-enabled keys.

   - Rust opens the IDE-context named pipe with `SECURITY_SQOS_PRESENT |
     SECURITY_IDENTIFICATION` so the server can only identify, not impersonate.
   - Go `tui/ide_context/fetch_windows.go` calls `windows.CreateFile` with
     `FILE_ATTRIBUTE_NORMAL|FILE_FLAG_OVERLAPPED` only. Gap = SQOS flags.
5. `ff770113ca` #39046 "Restrict MCP HTTP redirects to the configured origin"
   - Rust follows redirects only within the configured server origin, requires HTTPS
     for non-loopback redirects, enforces a 10-hop limit, and avoids replaying
     plaintext proxy credentials.
   - Go `mcp/http_client.go` uses Go's default redirect policy (cross-origin hops
     allowed). Gap = same-origin + HTTPS redirect policy.
6. `d0fd4e830a` #39040 "Preserve foreign paths in managed network approvals"
   - Rust keeps network-approval trigger cwd as `PathUri` and rejects turn environment
     working directories larger than 8 KiB at the thread-manager boundary.
   - Go `turn.TurnStartParams.Validate()` has no environment-cwd size bound. Gap = 8 KiB
     bound (foreign-path rendering is architecture-different; Go uses native strings).
