## Result

Equivalent implementation was already present, with new regression coverage.

- Go constructs a Guardian review as a dedicated model request instead of
  spawning a managed reviewer session that inherits the parent's environment.
- The request carries the resolved reviewer policy, model selection, bounded
  transcript evidence, and permission evidence. It does not carry the parent's
  tool catalog, MCP bindings, extension registry, or user instructions.
- `guardianTurnStart` skips executor MCP discovery for Guardian turns, and
  required-skill discovery exempts the isolated reviewer.
- Isolation is independent of the reviewed thread's subagent attribution.
  Ordinary review and subagent turns continue to inherit their normal context.

`appserver/guardian_isolation_like_rust_test.go` pins the request boundary: a
review of an MCP-looking action has no tools, has Guardian task/originator
attribution, and retains only its explicit permission evidence.
