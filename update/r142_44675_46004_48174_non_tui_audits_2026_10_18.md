# Non-TUI audits: global instructions, socket grants, usage-limit analytics

## `#44675` Global instructions at request boundaries

Go keeps the applied global-instructions snapshot, re-discovers repository
instructions when the working directory changes, inherits subagent snapshots,
and refreshes between long-turn model requests while warning once per episode.
App-server global-instruction tests pass.

## `#46004` Attachment Unix socket grants

The controller socket policy remains optional, so an omitted controller value
defers to the attachment policy; capturing a policy for an attachment resolves
the effective value distinctly from an explicit false. Network and exec-server
policy tests pass.

## `#48174` Usage-limit windows in analytics

Usage-limit windows are preserved on turn and compaction analytics events and
on API errors, including the error display/recovery lane. Telemetry and model
usage-limit tests pass.
