5. Rust 回归：`writable_roots_protect_gitdir_target_outside_alias_root`（`permissions.rs:2651`）断言 `root(writable).read_only_subpaths == vec![gitdir]`。

## 6. 未决问题 / 风险
- Go 的 `WritableRootsWithProtectedSubpaths` 是平台无关函数，本实现**不做 OS 门控**（Rust 只在 Linux/macOS 启用）；对 Linux 主路径行为与 Rust 一致，非 Linux 下也只是多一条 carveout（无副作用）。回归测试文件带 `//go:build linux`。
- 与 Rust 的差异（记为已知、非契约）：Rust 对**同 root** 的 `.git` 指针（`default_read_only_subpaths_for_writable_root`）会同时保留 raw 与解析后路径；Go 只追加 **canonicalize 后**的目标。对 `IsPathWritable`/bwrap carveout 判定而言 canonical 路径已足够（本单 RC 已证），raw inode 掩蔽仍由既有 `ProtectedSubpaths` 里的 `<root>/.git` 承担。
