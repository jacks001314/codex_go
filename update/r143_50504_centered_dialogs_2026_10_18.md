# `#50504` centered generic dialogs

- Rust 依据：`d42aecc56be30bda8df6137c1d74d6ed9365a23f`。
- 大部分选择/设置类 modal（generic/review/exit/misalignment/rate-limit/
  experimental/status/title/presets/config/theme/pets/memories/goal/skills/
  hooks/agents/permissions/usage/sandbox/worktree/import/picker）现在通过
  ANSI-aware 合成居中覆盖在 retained fullscreen base view 上，composer 与
  背景仍可见。
- 覆盖按显示列裁剪/补齐，支持宽字符与已有 ANSI；对话框超过终端尺寸时回退到
  旧 appended 布局。
- modal 先按窄 2 列 render 再套边框，避免边框/宽度导致标题与描述截断。
- 长 option 行在套边框前做 ANSI-aware wrap，disabled reason 不再被截断。
- approval/elicitation/user-input/feedback-note/voice-channel/plugin-browser
  也已迁移；textarea 的光标块随 modal 内容原位渲染，plugin-browser 测试改为
  通过 retained state 验证被对话框覆盖的历史。
- 输入仍由原 modal 路径拥有。

剩余：

- 共享 `openModal` 路径支持 parent stack：child overlay 以 parent dialog 为
  backdrop，child cancel/submit 后恢复 parent；thread reset 会清空 stack。
- 仍有部分专用 modal 直接赋值 `m.modal`，绕过 stack helper。
- host 级 cursor placement 与 section ownership 仍没有显式 overlay 路由。

验证：

- `go test ./tui/tea -run 'GenericConfirmationRetainsComposer' -count=1`
- `go test ./tui/... -count=1`
- `go vet ./tui/tea ./tui/chatwidget ./tui/markdown ./tui/streaming ./tui/history_cell ./tui/bottom_pane ./tui/status`
