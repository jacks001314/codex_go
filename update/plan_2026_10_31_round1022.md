## Goal

Mirror Rust #41424 (`f9cdc90c2c`): preserve the context baseline inherited by a
nested agent fork even when the fork removes the parent turn's user message.
A surviving full world-state snapshot must restore the previous turn settings
and reference context, while partial snapshots and snapshots superseded by a
newer compaction must not.

## Implementation

- `rollout/context_baseline.go` (new):
  - `ContextBaseline` carries the recovered turn-context payload and replayed
    world-state snapshot.
  - `ReconstructContextBaseline` replays rollout lines into `turn_started`
    segments and scans them newest-first, matching Rust's
    `finalize_active_segment`.
  - A segment establishes a baseline when it counts as a real user turn or
    contains a full world-state snapshot newer than its latest compaction.
    Bare turn-context records, patch-only segments, and full snapshots before
    the latest compaction do not establish one.
  - `thread_rolled_back` drops whole newest segments; only segments that count
    as user turns consume the rollback turn budget, so a context-only fork
    segment is discarded without becoming a rollback boundary.
  - World state is replayed in surviving chronological order: compaction
    resets the baseline, a full snapshot replaces it, and RFC 7386 merge patches
    apply only when a baseline exists.
- `rollout/session_items.go`: `applyRolloutContextMetadata` now starts from
  `ReconstructContextBaseline(lines)` for `Metadata.TurnContext` and
  `Metadata.WorldState`. The existing per-line projection still restores
  model, CWD, approval, effort, and permission metadata.
- `parity/rust_inventory_test.go`: register the `guardiancontext` top-level
  package added by Round 1021 so the Go/Rust directory inventory remains
  complete.
