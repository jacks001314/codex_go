# Rust #42598: report MCP tool discovery errors in server status

Upstream commit: `8f31b64c7f9ef67d8f966bff5ddf9e08eafe0b4d`

## Result

Equivalent implementation was already present.

- `MCPServerStatus` carries nullable `toolsError`.
- Startup or tool-list failure with no catalog sets the field while the server
  remains listed; healthy servers in the same response remain unaffected.
- Cached or empty catalogs return `toolsError: null`.
- Status clones deep-copy the error pointer, and the wire shape always emits the
  nullable field for compatibility.
