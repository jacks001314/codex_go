### G2 (#38947) Windows legacy managed config

- `config/config.go`: rework `managedConfigPath` into
  `managedConfigPath(codexHome, override)` + `managedConfigPathDefault(codexHome)`
  and add `ignoreDefaultManagedConfigOnWindows(codexHome, override)` (true on
  Windows when no explicit override).
- `config/config.go` `LoadWithOptions`: on Windows without an override, skip
  loading the default managed config; if the deprecated file exists, record a
  startup warning with the Rust message ("Ignoring deprecated managed config
  file at <path>; CODEX_HOME/managed_config.toml is no longer supported on
  Windows. Use %ProgramData%\OpenAI\Codex\requirements.toml for enforced
  settings or config.toml for defaults.").
- `config/api.go` `ConfigService`: keep the explicit
  `CODEX_APP_SERVER_MANAGED_CONFIG_PATH` override path; `loadManagedConfigLayerFromEnv`
  already only acts on the override. Add a
  `HasLocalManagedConfiguration(codexHome)`-style helper that on Windows checks
  only `requirements.toml` (mirrors Rust `has_local_managed_configuration`).
- `config/config_test.go` + `config/api_test.go`: Windows tests for ignored
  legacy settings, the startup warning, and detection through requirements.toml
  (guarded by `runtime.GOOS == "windows"` with an unexported seam for the
  platform decision).
