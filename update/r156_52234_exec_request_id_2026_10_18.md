# `#52234` Support request IDs in exec-server WebSocket handshakes

Rust 依据：`54685110a730ff2186f27c9f36d40ed83bae3071`。

- `EnvironmentAddParams` 新增 `websocketRequestId`；
- 在 `wss://` 或 loopback executor 上转发为 `X-Request-ID`，plain remote
  `ws://` 拒绝；
- 该 header 随 executor registration 保存，重连时继续使用；
- exec-server 的 WebSocket upgrade response 回显调用方提供的 `X-Request-ID`。

验证：

- `go test ./appserver -run 'EnvironmentAddWebsocketRequestIDLikeRust|EnvironmentAddAuthBearerTokenLikeRust' -count=1`
- `go test ./execserver -run 'EchoesWebSocketRequestID' -count=1`
