# `#50504` centered generic dialogs

- Rust 依据：`d42aecc56be30bda8df6137c1d74d6ed9365a23f`。
- 大部分选择/设置类 modal（generic/review/exit/misalignment/rate-limit/
  experimental/status/title/presets/config/theme/pets/memories/goal/skills/
  hooks/agents/sandbox/worktree/import/picker）现在通过 ANSI-aware 合成居中
  覆盖在 retained fullscreen base view 上，composer 与背景仍可见。
- 覆盖按显示列裁剪/补齐，支持宽字符与已有 ANSI；对话框超过终端尺寸时回退到
  旧 appended 布局。
- modal 先按窄 2 列 render 再套边框，避免边框/宽度导致标题与描述截断。
- 输入仍由原 modal 路径拥有。

剩余：

- approval/elicitation/user-input/feedback-note/voice-channel 等输入型路径，
  以及 permissions/usage/plugin-browser 等对 disabled reason 截断敏感的路径，
  仍保留旧布局。
- dialog cursor / section ownership 仍按底部 section 计算，没有 overlay 光标路由。

验证：

- `go test ./tui/tea -run 'GenericConfirmationRetainsComposer' -count=1`
- `go test ./tui/... -count=1`
- `go vet ./tui/tea ./tui/chatwidget ./tui/markdown ./tui/streaming ./tui/history_cell ./tui/bottom_pane ./tui/status`
