# Rust #41562: preserve turn lineage across goal continuations

Upstream commit: `4210c08defe92fe8828f789b6f9fda287ad3709e`

## Result

Implemented.

- Goal creation captures the active turn's root and parent turn
  (`setGoalTurnLineage`).
- Automatic continuations keep the trusted root and previous parent turn, then
  advance the parent after each goal turn (`extendGoalTurnLineage`).
- External objective edits, goal clears, and externally injected hook or
  response context invalidate stale lineage.
- Regression coverage includes anchor/invalidate behavior, continuation
  requests, and external inject invalidation.
