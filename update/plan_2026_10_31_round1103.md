## Findings

  ephemeral fork. Go's app-server fork uses the already-loaded source record
  (`applyThreadForkName`) and `session.Store.ForkRecord`; it never performs

  installed roots and uses `Arc` identity plus a generation to reject
  invalidated entries. Go has no loaded-plugins LRU cache; it owns only the
  manifest revision cache and validates installation paths while loading.

  `interactiveFullscreenTranscript` already defaults to true when the `[tui]`
  section is absent, `interactiveNoAltScreen` keeps alternate-screen
  restrictions authoritative, and the default is covered by tests.
