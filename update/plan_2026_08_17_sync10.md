## Gap: Vim operator engine

Rust's composer Vim mode applies operators (d delete, y yank, c change) to
motions and text objects. Go's Vim normal mode (added in the previous cycle)
only supported the line-operator repeats (dd/yy). Implemented the full
registered operator surface in `tui/tea/vim_mode.go`:

- Operators: d / y / c (start_delete_operator / start_yank_operator /
  start_change_operator) enter a pending-operator state.
- Operator motions: h / l / w / b / e / 0 / $ applied to the current line -
  dw (to next word start), dh (char left), db, de, d0 (to line start), d$
  (to line end), yw / c$ (change + insert).
- Text objects after i / a (inner / around): w (word), parens
  ( ( / ) / b as the innermost enclosing pair) - diw / daw / di( / da(,
  yiw (+ p paste).
- Line-operator repeats: dd / yy / cc (cc deletes the line and enters insert
  mode).
- Esc cancels a pending operator; an invalid motion/object key cancels and
  dispatches normally.
