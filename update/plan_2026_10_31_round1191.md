# Round 1191: create the setup marker with its protected DACL (2026-10-31)

Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

## Gap

Rust #42342 `prepare_setup_marker` builds the SDDL
`D:P(A;;GA;;;SY)(A;;GA;;;BA)(A;;GA;;;<real user>)`, passes it as the
`CreateFileW` security descriptor with `CREATE_NEW` and `dwShareMode = 0`, and
never exposes a marker with inherited permissions. Go created the file first
and then applied the same protected DACL through `SetSecurityInfo`, leaving a
window where a zero-length marker existed with the directory's inherited ACL.

  delegates to `openNoReparseWithSecurityDescriptor`, which sets
  `OBJECT_ATTRIBUTES.SecurityDescriptor` for `NtCreateFile` while keeping
  `OBJ_DONT_REPARSE` and the pinned root directory.
- `sandbox/windowssandbox/provisioning_files_windows.go`:
  `PrepareProvisioningSetupMarker` builds the Rust SDDL with
  `windows.SecurityDescriptorFromString` and creates the marker with that
  descriptor, dropping the `SetSecurityInfo` follow-up (and the now-unused
  `WRITE_DAC` access). `markerSecurityDescriptor` replaces
  `applyProtectedMarkerDACL`/`markerDACLEntries`.
