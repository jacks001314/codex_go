Runtime provider, matching the Mantle provider.

  Mantle provider, so Bedrock Runtime requests lost the client-agent header.
- Upstream #47964 removes the same reset in Rust's runtime provider builder.

  header for the Mantle provider and for Bedrock Runtime providers with and
