## Audit round against 4d3ed3f3b4

- `#57514`: `SwitchWorkspace` now revalidates the workspace allow-list after the
  token exchange and rejects switches taken over by an external authentication
  provider; `RollbackWorkspaceSwitch` refuses to restore credentials that moved
  on, rejects missing previous workspaces, and keeps the external-auth guard.
  `accountSession/list` revalidates authentication after its membership refresh,
  and the switch path refreshes the managed ChatGPT snapshot before unloading
  threads. The exchange client also refuses redirects so a `Bearer` token cannot
  cross origins. Tests: `auth/workspace_switch_like_rust_test.go`,
  `appserver/account_session_workspace_switching_like_rust_test.go`.
- `#57508`: output queue capacity now follows Rust's
  `MAX_INSTANCES * (OUTPUT_SLOTS_PER_INSTANCE + 1) + 1` (321 slots) instead of
  289, and the inbound `Packet` envelope uses a strict decoder that rejects
  unknown fields, missing members, `null` members, and non-`u64` instance IDs,
  matching `deny_unknown_fields`. Tests:
  `codemode/ui_plugin_like_rust_test.go`.
- App-server precomputed protocol exports were re-copied byte-for-byte from
  Rust `4d3ed3f3b4`; both SHA-256 anchors in `appserver/schema_test.go` were
  re-anchored (`accountSession/list` and `accountSession/switch` are now part
  of the exports).
- Parity manifests were re-anchored to the same Rust commit: new workspace
  members (`plugin-host`, `direct-tool-timing`, `ext/guardian-v3`,
  `message-board`, `utils/critical-path`, `utils/head-tail-buffer`), refreshed
  critical file hashes, fixture counts, and unified-exec test inventories.
  `runtime_agent_instances` was added as an under-development, default-off
  feature flag.

Remaining known difference (documented, not ported): Rust's workspace token
exchange attaches `default_headers()` (`originator`, `User-Agent`, and managed
residency). Go's auth layer has no process-wide default-header builder and the
managed residency requirement is config-scoped in `appserver`, so
`ExchangeWorkspaceToken` sends only `Authorization` and `Content-Type`.
