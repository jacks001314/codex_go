# Rust #44611: root turn attribution in turn-start events

Upstream commit: `196964ef10db326047c3e71fc568693cbd7c58a8`

## Result

Implemented with one missing shell-command path closed.

- `rollout.AppendTurnStartedWithRoot` already writes `root_turn_id`, omits it
  for legacy records, and rollout replay already carries the value into
  `Turn.RootTurnID`.
- Regular turns and manual compaction already persist turn-start events with
  attribution.
- Standalone `thread/shellCommand` turns previously emitted only client
  notifications. They now write `task_started` (attributed to their own turn,
  since there is no inherited root) and `task_complete` to the rollout, so
  history reconstruction sees a complete turn boundary.
- Shell commands reusing an active turn do not emit a second turn lifecycle.
