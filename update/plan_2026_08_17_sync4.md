### #38899 Move requirements policy ownership to execpolicy

Pure Rust-internal refactor: `RequirementsExecPolicy` (struct + order-independent
fingerprint equality + `AsRef<Policy>`) moved verbatim from
`config/src/requirements_exec_policy.rs` to `execpolicy/src/policy.rs` and
re-exported from `codex-config`. No Go-visible behavior, wire, schema or config
surface changed; no Go alignment work required.

### #38902 Honor per-environment shell variable policies

Rust now carries `ShellEnvironmentPolicy` in each resolved `EnvironmentConfig`
(`protocol/src/environment.rs`), infers it from the thread configuration when an
environment has no resolved config (`inferred_environment_config`), and applies
the selected turn environment's policy (`TurnEnvironment::shell_environment_policy`)
for shell commands, user shell tasks, and unified exec - previously Go parsed /
merged / validated `shell_environment_policy` but never applied it in the
app-server turn path.

Go alignment:

- `appserver/environment_config.go`: `EnvironmentConfig` gains
  `ShellEnvironmentPolicy` (protocol parity) with parsing, serialization (thread
  metadata roundtrip), deep-clone, and thread inference in
  `threadEnvironmentConfigForTurn` (Rust `inferred_environment_config`).
- `appserver/runtime_router.go`: the tool registry receives the thread-derived
  policy; `unifiedExecEnvironmentsForTurn` carries each resolved environment's
  policy on `tool.UnifiedExecEnvironment`.
- `tool/shell_executor.go`: the executor resolves the thread-derived policy with
  the environment's resolved policy winning, and sets `ShellRequest.EnvPolicy`
  (+ thread id), mirroring `TurnEnvironment::shell_environment_policy()`.
- `tool/runner.go` / `tool/unified_exec.go` / `tool/unified_exec_process_windows.go`:
  local shell and unified exec build the command env via
  `execpolicy.CreateEnv` (inherit none/core/all, default excludes,
  exclude/include_only patterns, set overrides, filters table); the remote
  exec-server receives the policy as `ExecEnvPolicy` (replacing the hardcoded
  inherit-all default).
- New leaf package `codex_go/execpolicy` (mirrors the `codex-execpolicy` crate
  split): the env-policy types + `CreateEnv` + `EnvPolicyFromShellEnvironmentPolicy`
  moved out of `codex_go/exec` (which imports `tool`, so the tool layer could not
  use them without an import cycle); `codex_go/exec` re-exports the surface for
  existing callers, and the CLI sandbox converter delegates to it.
