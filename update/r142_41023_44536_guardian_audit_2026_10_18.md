## `#41023` Guardian reviewer turn/tool analytics

已具备：

- `emitGuardianReviewMetrics` 记录 review count、duration、TTFT、token usage
  与 decision/terminal/action/session attribution。
- `review_analytics.go` 记录 Guardian V2 classification/fast-decision events。
- 现有测试：`GuardianReviewCompletedEmitsReviewAnalyticsLikeRust` 与 Guardian
  metrics tests。

未具备：

- Rust 把 private Guardian session 的 `TurnStarted`/`TurnComplete`/`TurnAborted`
  和 canonical tool item 事件转换为 Codex turn/tool analytics notifications。
- Go 的 `guardianSessionRunner` 直接调用 model agent，不经过 app-server turn
  analytics bridge；没有 `track_guardian_session_event` 或
  `tracked_tool_item_id` 对应路径，也没有 reviewer turn/tool usage 计数。

因此记录为 partial：review 级 metrics 已对齐，但 reviewer session 的 turn/tool
analytics 仍缺失。

## `#44536` Move Guardian reviewer settings/execution into reviewer crate

Rust 的 crate 拆分是结构性重构；Go 没有多 crate 布局，Guardian reviewer
settings/execution 当前分布在 `appserver` 与 `model` 包内，行为接口保持等价。
没有需要搬运的同名 crate 边界，记录为 not_applicable（结构差异）。
