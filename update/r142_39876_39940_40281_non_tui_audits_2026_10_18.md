# Non-TUI audits: existing realtime calls, code-mode startup, image content kinds

## `#39876` Attaching to existing realtime calls

Go attaches to existing realtime calls with the negotiated voice, skips startup
context/session updates for an existing call, and retries sideband attachment
within a bounded budget with 410 handling. Realtime tests pass.

## `#39940` Local code-mode host startup

Go's local code-mode host uses the longer startup timeout from upstream, so a
slow local host is not cut off prematurely. Code-mode tests pass.

## `#40281` Content kinds during image preparation

Image preparation preserves content kinds and marks preparation errors with the
`images.preparation_error` kind. Model tests pass.

## Verification

- `go test ./realtime -run 'ExistingCall|Attachment|Sideband' -count=1`
- `go test ./codemode -run 'LocalHost|Startup|Timeout' -count=1`
- `go test ./model -run 'ImagePreparation|ContentItemKinds|PreparationError' -count=1`
