## 1. 逐条实现要点

### #60270 模型列表告警

`ModelCatalogResultMsg` 落地后检查当前 OpenAI provider 模型是否在 catalog 中；ChatGPT 账号下缺失时写一条可见 warning，且每个会话只写一次。

### #60271 overview 关闭语义

`AgentsOverviewView.Cancel()` 只在 `ExitOnCancel`（存在当前会话或启动会话待定）时返回 `ActionExit`；模型只在 `ActionExit` 时关闭 command center。初始无会话时 Esc 保持 dashboard 打开。

### #60320 无 item 的 Cloud 失败

`remoteTUIThreadMessagesFromThread` 每个 turn 都会追加 `turn.Error` 的 system 消息，空 items 的失败 turn 不会被丢掉；older-history loader 直接分页原始 turn 摘要，不做行数裁剪。

### #60327 过期 stream 断开

新增 `streamLossState{remaining,superseded}`：stream 结束时记录并排队断开通知；成功 replacement 对同一 thread 的未投递损失执行 supersede；通知泵按队列顺序只丢弃被覆盖的损失，未替换的断开仍投递。

### #60335 恢复后重复回答

恢复的 assistant 消息保留 upstream item id；`mergeAssistantFinalForItem` 在同 item id 上原地替换并清掉迟到的同 id 片段，最终只有一条回答。

### #60342 goal objective 不可信

continuation 模板不再内嵌 objective，改为引用 `goal_objective` 上下文；三条 continuation 路径（in-process appserver、remote TUI、embedded TUI）都以 `untrusted` kind 携带 objective。创建 goal 的 turn 中，objective 仍以 `create_goal` 工具输出（不可信来源）呈现。

### #60389 Cloud Apps 预热门

`PrewarmRequest` 追加 field 28 `PluginsMcp{product_sku:"codex"}`，与 Rust `prewarm.rs` 的 wire 形状一致。

### #60390 MCP 输出延迟

`ThreadItemOutputDeferral` 增加 `mcpToolCall`；仅对 completed、无 error、非 `codex_app`、无 widget/app 资源、无 structuredContent/meta、content 全为纯文本且非空的 MCP 结果清空 content 并置 `outputDeferred`。纯文本判定排除 JSON 与 fenced 代码；`thread/items/read` 仍返回完整内容。持久化截断对成功纯文本结果保留 `Truncated tool output:` 可读预览。

### #60391 Guardian 指引

模板文案与 Rust `prompts/templates/guardian/policy_template.md` 对齐（去掉“clearly and explicitly”“default”等冗余限定）。
