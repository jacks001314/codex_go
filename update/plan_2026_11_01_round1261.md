## Gap

Rust #57657 keeps the reloadable trace bridge installed when tracing starts
disabled and replaces the global tracer provider with a no-op provider when
tracing is turned off. Go already had the provider reloader and the tracer
clearing path, but the acceptance coverage only exercised a metrics collector.
There was no regression test proving that an account switch can activate a
trace exporter after startup and that the newly exported request spans preserve
the inbound parent trace.
