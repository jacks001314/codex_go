## 本轮落地

### `#54257` Realtime frame-recency transcript

- `realtime/wire.go` 为 V3 `input_transcript.added` /
  `output_transcript.added` 解析顶层 `start_ms` 与 `end_ms`。
- `realtime/transport.go` 维护帧序号和每个 utterance 的 raw frame；
  新帧到来时才执行跨帧淘汰，同帧事件只对当前帧条目做单项限额。
- 同一帧内 input/output 等权，按会话顺序保留双方后缀；延迟 final 通过
  `truncatedPrefixBytes` 判断是否能扩展已裁剪文本，且不会把旧 utterance
  错误提升为最新帧。
- 无时间戳的 V1/V2 与 legacy 输入继续走原 FIFO 回退。

验证：

- `go test ./realtime -count=1`
- `go test ./realtime -run 'TestRealtimeTransportPreservesRecentSpeechByFrameLikeRust|TestParseRealtimeTranscriptFrameLikeRust|TestTrimRealtimeTranscript|TestRealtimeTransportBoundsActiveTranscriptLikeRust' -count=1`

### `#41879` Guardian review evidence across compaction

- `appserver/guardian_review_history.go` 新增线程级独立 review history：
  在 compaction 替换 `record.Items` 前捕获完整证据，后续 live append
  增量更新，`thread/revert` 按 `beforeTurnId` 截断。
- legacy rollout 可通过 `rollout.ReviewHistoryItems` 重建原始证据；
  compaction replacement 被跳过，rollback marker 仍生效。
- Guardian transcript 的 tool call/output 归属统一为
  `tool <name> call` / `tool <name> result`；orphan output 使用
  `tool result`，匿名且无名字的 output 不再伪装成用户证据。
- rollout 工具条目补回 `arguments`/`output` 文本，避免从 legacy
  记录恢复时只剩空 role。

### `#42065` Guardian history across reconstruction

- `rollout.CompactedEvent` 增加可选的 `guardian_history` 数组，
  `AppendCompactedWithCheckpoint` 与生产 compaction 路径写入该字段。
- 独立 review history 按 user / non-user 各 128 条、各 4 MiB 限额，
  超限时淘汰同一类最旧的一半；用户文本超限时保留有界前缀，工具类
  超限项跳过。
- `CompactedGuardianHistory` 从最新 checkpoint 恢复证据；
  `guardianReviewHistoryItems` 将其与当前 record 合并。
- 用户 fork 复制存活 turn 窗口（支持 `lastN` 和 `beforeTurnId`），
  subagent spawn 建立空的独立 history，避免继承父线程授权；
  `thread/revert` 截断 review evidence。
