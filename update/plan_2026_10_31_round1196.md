## 58418

Rust inlined RecordedExecCall into guardian/recorded_tool_call.rs and made the
review return GuardianReviewResult directly. The Go port already has the same
semantics in appserver/thread_guardian_review.go, so no Go change was needed:

- guardianRecordedExecCallFromItems accepts only a completed plaintext
  default-namespace exec_command with a nonempty call ID.
- prepareRecordedExecCommand parses arguments and the environment, prepares the
  command with the UnifiedExec lifetime, and rejects apply_patch-intercepted
  commands.
- An explicit policy skip returns the call ID with no assessment.

## 58395

Added the host-scoped MCP request metadata hook:

- mcp/tool_request_meta.go: MCPToolRequestMetaHook and
  MCPToolRequestMetaProvider mirror Rust tool_request_meta.rs. The hook matches
  the server name, remote tool name, local environment, registration source and
  full transport; it refuses to overwrite an existing key, and a missing
  metadata object or provider error fails the call before dispatch.
- mcp/tool_executor.go: ToolRequestMetaHook option, applied in Execute right
  after request meta is built (errors surface to the model as tool output).
- turn/tools.go: MCPToolRequestMetaHook option forwarded to every executor.
- appserver: RuntimeServices.MCPToolRequestMetaHook default plus per-thread
  SetThreadMCPToolRequestMetaHook overrides, wired into the turn tool options.
