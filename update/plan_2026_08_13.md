### Implement in this batch

1. **Enforce non-interactive approval policy for Codex delegates**
   (`95aada11c4`, #38205)
   - Rust:
     - `codex_delegate.rs`: `run_codex_thread_interactive` /
       `run_codex_thread_one_shot` reject any config whose approval policy is
       not `never` and constrain the delegate policy to `never`.
     - Deleted the delegate approval forwarding machinery (exec / apply_patch /
       request_permissions / request_user_input / MCP approvals forwarded to
       the parent session); delegates now run with `never` so approval-gated
       commands and MCP tool calls are denied inside the delegate.
     - `mcp_tool_call.rs`: `request_mcp_tool_user_approval` returns
       `ReviewDecision::denied(...)` when the approval policy is `never`.
     - `mcp_skill_dependencies.rs`: `should_install_mcp_dependencies` returns
       `false` when the approval policy is `never` (after the full-access
       auto-approve check, which still returns `true`).
     - Removed legacy RequestUserInput MCP approval compatibility tokens and
       the `mcp_approvals_reviewer`/`request_permissions_for_cwd` helper
       surfaces used only by delegate forwarding.
   - Go mapping (architecture delta: Go review/guardian run as direct
     model runners, not delegate threads; Go has no delegate forwarding):
     - `exec/exec.go` `effectiveExecApprovalPolicy`: force
       `sandbox.ApprovalNever` when `req.Exec.Subcommand == "review"`,
       mirroring Rust `tasks/review.rs` plus the #38205 delegate-level
       enforcement.
     - `appserver/turn_runtime.go`
       `maybePromptAndInstallSkillMCPDependencies`: when the effective turn
       approval policy is `never` and the missing-dependency install is not
       full-access auto-approved, skip the prompt entirely (do not prompt, do
       not install), mirroring Rust `should_install_mcp_dependencies` order
       (auto-approve -> true; never -> false; else prompt).
     - MCP tool-call approvals: Go `HandleMCPElicitation` already declines
       approval requests under `never` (full-access empty forms auto-accept,
       matching the Rust full-access auto-approve path); no code change
       needed, covered by existing tests.
     - Delegate forwarding: Go has no parent-session forwarding for
       sub-agents; no equivalent deletion needed.
