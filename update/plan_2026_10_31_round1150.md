## Findings

- Rust #42113 threads the executor's platform through command parsing,
  executable-name normalization, and dangerous-command classification, so a
  command aimed at a remote Windows executor cannot slip past safety checks
  that only understand the host OS.
- Legacy executors that report no platform keep host semantics. Any other
  reported platform uses Windows rules conservatively, and `linux`/`macos`
  use POSIX rules.
- A dangerous command can never run without approval: `Never` rejects it,
  while on-request, unless-trusted, and granular prompt for it. The
  `exec_command` rejection is bounded and never echoes the raw command beyond
  that budget.
- Go already had `DangerousCommandPlatform`, `HostDangerousCommandPlatform`,
  platform-aware executable identity, the bounded launch-failure message, and
  monotonic process IDs from round 1032. It lacked the classifier itself and
  any call site that could act on a match.

## Changes

- `execpolicy/dangerous_command.go`: port Rust's classifier, including
  `rm` force-option variants, `sudo`/`env`/`trap` wrapper unwrapping with the
  depth-8 fail-closed bound, `bash|zsh|sh -lc|-c` literal-command extraction
  (dynamic arguments are omitted, matching Rust's node parser), PowerShell word
  matching, platform selection from the executor OS, and the rejection reasons.
- `execpolicy/dangerous_command_windows.go`: port the Windows rules for
  `Start-Process`/`Invoke-Item`/ShellExecute URLs, `Remove-Item -Force` and CMD
  `del /f`, `rd /s /q`, `echo hi&del`, browser/`mshta`/`rundll32` launches,
  plus the helper tokenizers.
- `tool/dangerous_command.go`: apply the requirement at the unified-exec
  preparation boundary (Rust `process_manager`): reject under `Never`, force
  approval otherwise, and skip the gate for an already-approved call.
- `tool/shell_executor.go`: resolve the platform from the selected
  environment's reported `PlatformOS`, falling back to host semantics when the
  environment is local or the executor is legacy.
- Tests: `execpolicy/dangerous_command_like_rust_test.go` covers forced-rm
  variants, wrapper depth, complex shell syntax (pipes, loops, substitutions,
  traps), quoted/dynamic non-matches, PowerShell words, Windows CMD/PowerShell
  rules, and platform selection. `tool/dangerous_command_approval_like_rust_test.go`
  covers the bounded remote-Windows rejection, on-request approval gating, and
  executor-platform selection independent of the host.
