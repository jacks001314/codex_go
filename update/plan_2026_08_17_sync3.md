## Dynamic verification infrastructure (explicit cycle focus)

### L2 record-replay harness generalized (`record-replay-harness-generalized`)

The facility previously only replayed the single `oss-story.jsonl` fixture
(fully completed tasks, reasoning + agent_message surfaces only). The harness
is now shape-driven:

- `recordreplay/core.go`: the scripted agent additionally maps a plain
  `message` msg type to an agent_message item, and the core cross-check treats
  `message` as agent_message presence.
- `recordreplay/harness_test.go`: synthetic traces (reasoning-only task,
  plain-message task, in-progress task truncated before task_complete) replay
  through the app-server core with the same observable-contract checks
  (notification stream + persisted paginated rollout + Resume
  recoverability); the recorder-level contract pins that an uncompleted turn
  persists task_started/item lines without fabricating a task_complete.
- `recordreplay/property_test.go` (djalign method 5): Event JSON roundtrip
  fixed point, digest determinism, unknown-kind no-swallow (future
  kinds/variants surface in OtherKinds/AppVariants), and documented
  volatile-field drops (ts/cwd/model text -> presence). The property corpus is
  deterministic and Rust-checkout-free, so these tests run in any CI without
  `CODEX_RUST_ROOT`.
