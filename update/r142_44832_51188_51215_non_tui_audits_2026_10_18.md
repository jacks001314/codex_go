# Non-TUI audits: enterprise MCP auth, base instructions, raw MCP catalog metrics

## `#44832` Trusted enterprise MCP auth

Go parses `oauth.authorization_server_issuer` as an EMA-only setting, gates
enterprise refresh-token authorization behind the feature flag, blocks ordinary
MCP OAuth login for EMA servers, and keeps trusted IdP values at the config read
boundary. Config, app, and app-server EMA tests pass.

## `#51188` Base instructions in incremental tool history

Go stores the base-instructions world-state section, includes it in the
top-level tool snapshot, and renders the base-instructions diff only when the
window changes. Session and app-server incremental-catalog tests pass.

## `#51215` Raw MCP tool catalog size telemetry

Go records per-server raw catalog size records with source/SKU attribution and
cached-source reporting, and emits the binding-catalog telemetry from the
app-server catalog path. MCP, telemetry, and app-server catalog tests pass.
