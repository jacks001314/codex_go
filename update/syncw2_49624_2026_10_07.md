## 3. cwd override 定性（本单唯一残留项）

**Rust 侧该 override 只在这三个参数里体现**：`codex-rs/tui/src/app_server_session.rs:2300-2311 thread_cwd_from_config`（`Remote` 模式 → `remote_cwd_override`），被 `:2162`（thread/start）、`:2227`（thread/resume）、`:2277`（thread/fork）使用；全文其余 `remote_cwd_override` 使用点都是这三者及其构造器。

**这四条命令的 RPC 参数在两侧都没有 cwd 槽位**：

```
Go   appserver/protocol.go:2036  ThreadArchiveParams   { ThreadID }
Go   appserver/protocol.go:2051  ThreadUnarchiveParams { ThreadID }
Go   appserver/protocol.go:2066  ThreadDeleteParams    { ThreadID }
Go   appserver/protocol.go:2782  ThreadQueueAddParams  { ThreadID, Input, ClientUserMessageID }
Rust 同形（thread/archive、thread/queue/add 等均为 threadId + 各自既有字段，无 cwd）
```

⇒ 对 `archive/unarchive/delete/queue` 四条命令，`with_remote_cwd_override(cli.cwd)` 是**空操作**，没有可承载它的线上字段，**无从落地**。
`git grep -In 'with_remote_cwd_override\|RemoteCwdOverride\|remote_cwd_override' -- '*.go'` = **0 命中**（预期，非缺失）。

补：override 真正可观测的面（remote **thread/start**、**thread/fork**）Go **已**转发 caller cwd —— `app/remote_tui.go:4552`（`CWD: strings.TrimSpace(shared.CWD)`）、`app/remote_tui.go:4593-4595`（fork `params.CWD`）。故即使按可观测面衡量，也已对齐。
