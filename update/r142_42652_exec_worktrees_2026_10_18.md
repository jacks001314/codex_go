# #42652 Add managed worktrees to `codex exec`

## Upstream change

Rust adds shared `--worktree` parsing for new and forked exec sessions, creates
the session in a managed Git checkout, binds that checkout to the thread, and
rejects unsupported execution modes before allocating a worktree.

## Go carriers

- `cli.parseExec`/shared exec options parse `--worktree` and `--no-worktree`,
  including the fork form.
- `exec` resolves the configured desktop worktree pool, allocates a managed
  checkout, and uses its cwd as the session/thread working directory.
- `validateExecWorktreeRequest` rejects remote execution,
  `--ignore-user-config`, ephemeral sessions, resume, review, and unsupported
  subcommands before allocation.
- CLI allocation leaves automatic cleanup disabled, matching the CLI ownership
  policy.

## Verification

- `go test ./cli ./exec -run 'Worktree' -count=1`
