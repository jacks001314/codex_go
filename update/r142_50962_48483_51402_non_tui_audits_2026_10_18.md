# Non-TUI audits: stable environment tools, Windows console suppression, turn attribution

## `#50962` Stable environment tool exposure

Go gates environment-backed tool advertisement behind
`stable_environment_tools`, carries turn readiness facts into command,
apply_patch, request_permissions, view_image, and write_stdin executors, and
keeps the selectors stable as readiness changes. Focused turn/tool exposure
tests pass.

## `#48483` Windows console suppression

Go sets `CREATE_NO_WINDOW` for piped Windows helpers through
`envutil`/`appserver` and the shared spawn paths, preventing transient console
windows. The dedicated `envutil` console test and app-server console/window
tests pass. The exec-server run still hits the pre-existing PowerShell fallback
baseline (`TestWindowsSandboxPowerShellFallbackWithoutCompatibleShellLikeRust`),
which is unrelated to console suppression.

## `#51402` Turn attribution recovery and compaction

Go persists regular-turn attribution in the `turn_started` rollout, reconstructs
it for cold recovery, and carries root-turn lineage and compaction resume
metadata through checkpoints. Rollout, session, and app-server attribution
tests pass.
