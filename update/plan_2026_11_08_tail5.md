### 1.3 判定：`partial`

缺的是"取数位置"，不是"提醒功能"本身。三个可观测后果：

1. **非本进程客户端拿不到提醒**。`app/remote_tui.go` 对 `securitySetup` 无任何引用（`rg securitySetup app/remote_tui.go` → 0 命中），所以经 app-server 连进来的前端永远看不到安全提醒，而 Rust 侧现在正是为了这个才把它搬进 app-server。
2. **runtime auth 语义不同**。Rust 要求走 `runtime_auth_for_config` + `auth_provider_for_request` + `validate_headers`；Go 把 runtime auth 当可选注入传给 CloudClient，凭据仍以 `auth.json` 的 `Bearer` 为主。在 runtime agent instance（企业 runtime 鉴权）场景下，两边取数身份可能不同。
