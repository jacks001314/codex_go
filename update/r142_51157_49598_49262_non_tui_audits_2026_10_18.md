# Non-TUI audits: required skills, goal edits, turn-phase tracing

## `#51157` Required environment skills before inference

Go stores `EnvironmentSkillsParams` on environment registration, snapshots the
required skills for a turn, and gates the first model request until every
required skill is enabled. Missing or disabled requirements fail before
inference; the Guardian session-source exemption is covered. Focused app-server
and turn tests pass.

## `#49598` Explicit user goal edits in model history

The `thread/goal/set` and `thread/goal/clear` paths tag host-originated goal
instructions, `context/user_goal.go` renders the persisted goal fragment, and
`exec/goal_retention.go` preserves the host-annotated goal across compaction and
history replacement. Context, exec, and app goal tests pass.

## `#49262` Turn-phase tracing and accepted-input correlation

Go emits `codex.turn.phase` sampling/tool-blocking spans, a compaction span,
mailbox-preemption records, and correlates accepted input with the assigned turn
ID. Turn and telemetry span tests pass.
