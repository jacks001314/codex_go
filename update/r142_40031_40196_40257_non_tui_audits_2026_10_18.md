# Non-TUI audits: strict MCP review, content kinds, `cua_repl`

## `#40031` Strict MCP auto-review outcomes

Go preserves canonical approved, denied, timed-out, and aborted review outcomes
for strict MCP elicitations instead of collapsing them into a generic decline.
App-server MCP elicitation tests pass.

## `#40196` Content-kind annotations

User message content kinds (`user.text`, `user.image`, `user.audio`) are attached
to model input items and contextual fragments, and app-server tests pass.

## `#40257` `cua_repl` support

Go's Node-REPL-backed server check and namespace helper include `cua_repl`,
including its namespaced form. App-server and MCP tests pass.
