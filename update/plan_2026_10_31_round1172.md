# Round 1172 audit plan (2026-10-31)

Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

This round closes the precondition recorded by `#39957` (blocked) and moves
`#42137` (partial) forward: local unified-exec launches now use the
executor-owned v2 shell snapshot instead of spawning the shell directly.

## Rust behaviour

`codex-rs/core/src/unified_exec/shell_snapshot.rs:169-196`
`shell_snapshot_request` attaches an executor snapshot request only when

- `Feature::ShellSnapshotV2` is enabled,
- the turn environment reports `shell_snapshot_v2_supported`,
- the launch cwd equals the environment's selection cwd,
- the resolved shell is a POSIX login shell,

and scopes it to `"{thread_id}:{environment_id}"`. The exec server
(`exec-server/src/shell_snapshot.rs` `ShellSnapshotCache::prepare`) then caches
the capture by request, cwd, environment policy and sandbox, and rewrites the
launch to restore it (`bash -pc` / `zsh -fc`, in-memory environment chunks up to
512 KiB, file replay above that).

## Go gap

`tool/unified_exec.go` spawned local launches with `osexec.Command` directly, so
the executor's `shell_snapshots.rewrite` never ran for local commands; only
remote launches carried `ShellSnapshot`. The executor cache also keyed entries on
the resolved environment, so a per-call `CODEX_TOOL_CALL_ID` would force a fresh
capture.

## Change

- `execserver/local_shell_snapshot.go`: `LocalShellSnapshotExecutor` owns the
  process-wide local executor cache with `Prepare` (the `process/start` rewrite)
  and `Prewarm` (capture only), plus `LocalShellSnapshotV2Supported`.
- `execserver/shell_snapshot.go`: `shellSnapshotKey` now mirrors Rust's entry
  identity (`scope request`, `cwd`, `env_policy`, `sandbox`), excluding the
  resolved environment so replay re-exports the launch's own values.
- `tool`: `ShellRequest.LocalShellSnapshot` plus `SnapshotProviderResult.Local`;
  the local launch prepares through `prepareLocalShellSnapshot` and runs the
  rewritten argv/env while recording the model's original command.
- `appserver`: `shellSnapshotV2ProviderForTurn` implements the Rust gate (feature,
  environment capability for local/remote, selection cwd, POSIX login shell) and
  composes with the session file snapshot when both features are enabled.
