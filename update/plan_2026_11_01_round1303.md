# Round 1303 — portability and concurrency findings from Linux

Rust target: `67f0994b532b8740f14b5b738af7b7b2a915b1d6` (anchor worktree
`D:\qax\reagent\dev\git\codex-anchor-67f0994b`, hash `67f0994b`).

This round reran the Go suites on Kali instead of treating the Windows result as
portable. It found five product defects and a set of fixtures that still encoded
Windows-only assumptions.

## Product defects

- `mermaid/width.go`: `go-runewidth`'s package helpers consult the host locale
  through `EastAsianWidth`, so U+2014 became two cells on a CJK host and the ER
  parser rejected valid output. Rust `unicode-width` has no locale mode; use a
  zero `runewidth.Condition` so ambiguous characters stay one cell.
- `execserver/server.go`: `capture`, `finishWithCode` and `finishStream`
  allocated a notification sequence outside the publish lock. Concurrent
  writers could allocate 1 and 3 and then publish 3 first, which the stdio
  transport rejects. `notifyMu` now spans allocation and publication.
- `config/external_cursor_import.go`: `writeExternalTOML` trusted a path that
  the import scope had resolved earlier. A repository `.gcode` replaced by a
  symlink was still followed; the write path now reruns the shared no-follow
  check.
- `config/external_session_connectors.go`: `filepath.VolumeName` recognizes a
  drive letter only on Windows. Treat an ASCII drive prefix as absolute on every
  host so a drive-qualified external cursor path cannot escape the expected
  relative root.
- `sandbox/policy_transforms.go`: a POSIX `:tmpdir` grant with an empty `TMPDIR`
  fell back to `os.TempDir()`, inventing a path the executor never reported.
  The grant now remains unresolved and fails closed, matching Rust.

## Fixtures that assumed Windows

- `config`: use a POSIX absolute path off Windows; pass `ManagedConfigPath`
  explicitly so a host `/etc/codex/managed_config.toml` cannot affect discovery;
  keep the legacy-default-file assertion Windows-only.
- `execpolicy`: environment names are case-sensitive on Unix, so retain the
  `codex_version`/`CODEX_VERSION` collapse only on Windows.
- `model`: give the Bedrock refresh helper a `#!/bin/sh` shebang, and allow the
  retry-delay assertion to absorb about 1 ms of deadline rounding.
- `appserverdaemon`: install fixtures for `codex-code-mode-host`, `rg` and bwrap
  must be executable, not mode 0600.
- `sandbox/seatbelt_test.go`: assert the resolved home root only among
  `WRITABLE_ROOT_*` parameters; `PROTECTED_ANCESTOR_*` legitimately retains the
  link spelling.
- `sandbox/windowssandbox/elevated`: the symbolic `/tmp` round-trip test asserts
  Windows path semantics and now skips elsewhere.
