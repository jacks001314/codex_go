# #45509 Share MCP tool specs until search results are selected

## Upstream change

Rust keeps search entries backed by `Arc<ToolSpec>` and normalizes loadable
specs only for selected results, avoiding eager schema copies for tools that
are never selected while preserving result formatting and cache equality.

## Go implementation

`NewToolSearchHandlerWithOptions` now retains the deferred catalog specs
directly instead of cloning each input schema while building the index. The
existing `cloneSpecForSearchOutput` still runs at selection time, so returned
results are independent copies while unselected tools remain unmodified.

path baseline failures (`TestUnifiedExecRestoresExecutorPathDirsForLoginShellLikeRust`
