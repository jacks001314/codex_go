# Non-TUI audits: code-mode execution delegates, post-turn compaction, realtime attachment

## `#44865` Scope code-mode callback delegates to individual executions

Upstream: `3305c4f31d4ab6542afa05b91e112f1d67e9744f`.

The existing implementation retained an invocation for each yielded cell, but
resolved nested calls and notifications by guessing from the runtime call ID.
That is ambiguous when two yielded executions are live and a nested call ID
does not encode its parent. The executor now retains an explicit cell-to-
invocation map:

- Nested tool calls and notifications use the cell ID as the authoritative
  owner, with call-ID matching only as the pre-admission fallback.
- Wait completion, cancellation cleanup, and host-initiated `cell_closed`
  release the retained invocation together with the cell.
- `TestCodeModeRoutesCallbacksToOwningYieldedExecutionLikeRust` keeps two cells
  live, uses nested call IDs without a parent prefix, and verifies both tool
  and notification callbacks reach the correct execution.

## `#46541` Add opt-in compaction after final responses

Upstream: `49e248d4c3ad76fc29519bd0aa9e532f448fa90f`.

Implemented:

- `model_post_turn_compact_threshold_percent` accepts 0 through 100 and rejects
  larger values; omitted or zero disables turn-end compaction.
- The threshold is checked against the usable context window or an existing
  auto-compaction limit. Pending input, cancellation, and token-budget mode skip
  the new path.
- The attempt records the distinct `postTurn` phase and runs before turn
  completion. Interruptions and aborts fail the turn; other failures warn while
  preserving the completed answer.
- Local summaries are committed only after successful compaction, and a missing
  or empty assistant summary does not replace history. Approval reviewers run
  through the dedicated Guardian session and do not take this turn-end path.

## `#51539` Completion-aware realtime attachment and session-scoped detach

Upstream: `4aaee872e31abefe0d32e91faab23b09b6968824`.

Re-verified the existing Round 207 implementation:

- Existing-call attachment joins a client-created call without session
  configuration and keeps bounded sideband activation retries.
- Replacing a conversation publishes the previous close before the successor's
  started event.
- A delayed detach carrying the replaced conversation ID returns
  `ErrRealtimeSessionMismatch` and leaves the replacement running; a matching
  session ID closes it.
