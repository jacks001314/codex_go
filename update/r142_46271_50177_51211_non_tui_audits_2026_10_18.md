# Non-TUI audits: MXC selection, writable file streaming, bubblewrap safety

## `#46271` MXC Windows sandbox selection

Go parses `mxc` in the Windows sandbox implementation list, treats it as ready
without legacy setup, and selects it explicitly where supported while retaining
the legacy fallback rules elsewhere. Config, sandbox, and tool tests pass.

## `#50177` Writable exec-server file streaming

The exec-server advertises `FileWriteStreaming`, supports `fs/open` replacement
mode with create/truncate semantics, and exposes positional writes for the
streaming path. Exec-server tests pass.

## `#51211` Sandbox-writable bubblewrap executables

Go filters bwrap candidates through the command's effective filesystem policy
before probing/launching, so a replaceable launcher is skipped in favor of the
packaged binary. I also fixed a cross-platform test build bug by moving the
platform-neutral `probeBwrapHelp` out of the Linux-only file and skipping the
Linux shell-stub control case on Windows.

## Verification

- `go test ./config ./sandbox ./tool -run 'Mxc|MXC|WindowsSandboxMode' -count=1`
- `go test ./execserver -run 'FileWriteStreaming|Replace|Streaming' -count=1`
- `go test ./sandbox/linuxsandbox -run 'Bwrap|Bubblewrap|Executable' -count=1`
- `GOOS=linux GOARCH=amd64 go test -c ./sandbox/linuxsandbox`
