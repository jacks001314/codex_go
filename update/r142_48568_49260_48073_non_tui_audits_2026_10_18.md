# Non-TUI audits: private IP upstream routing, enterprise MCP refresh, runtime grants

## `#48568` Exec-server private IP upstream routing

The trusted CLI flag and environment are carried into the executor's startup
routing, and the exec-server proxy applies the opt-in to permitted private
upstreams while retaining request policy. CLI and exec-server tests pass.

## `#49260` Enterprise MCP auth and config refresh

Enterprise MCP admission is restricted to the current registration/authority,
and a refresh that no longer matches fails closed instead of admitting the new
configuration. App-server enterprise/config-refresh tests pass.

## `#48073` Runtime-only permission grants and stdin approval

The runtime's own filesystem grants are reported separately from user grants,
so they do not trigger stdin approval; the credential-broker shell snapshot and
plugin sidecar grants reach the command profile correctly. App-server, sandbox,
and plugin tests pass.

## Verification

- `go test ./cli ./execserver -run 'PrivateIP|Proxy|Upstream' -count=1`
- `go test ./appserver -run 'Enterprise|MCPConfigRefresh|MCPEnterprise' -count=1`
- `go test ./appserver ./sandbox ./plugin -run 'InternalPermission|StdinApproval|Sidecar|RuntimeGrant' -count=1`
