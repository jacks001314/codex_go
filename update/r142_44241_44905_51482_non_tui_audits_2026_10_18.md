# Non-TUI audits: credential remapping, disabled plugins, PathUri skill identity

## `#44241` Credential provider source remapping

Config writes validate credential-provider edits, report source overrides, prune
displaced origins, and apply credential-broker state at the project sanitizer.
Config credential-provider tests pass.

## `#44905` Disabled plugin settings

Thread settings and resume/fork responses expose and restore the saved
`disabledPluginIds`; a supplied list replaces it, an empty list clears it, and
null/omission preserves it. App-server disabled-plugin tests pass.

## `#51482` PathUri skill identity

PathUri identity is used for structured skill mentions, implicit-skill doc and
scripts maps, and onboarding lookup. While verifying on Windows I found that
shlex tokenization consumed backslashes in host absolute command paths, so both
`demo%23skill` and `demo#skill` failed to match. The implicit-invocation path now
normalizes Windows absolute-path separators before tokenization, and the
home-expansion fixture sets `USERPROFILE` in addition to `HOME`.
