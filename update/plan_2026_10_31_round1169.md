# Round 1169 audit plan (2026-10-31)

Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

This round closes the residual of `#43447`: the turn's
`x-codex-turn-metadata` now asks the model-owned Guardian computer-use policy
before the legacy `node_repl_auto_review_required` bit, so every path that
decides whether computer use needs review agrees.

## Rust behaviour

`codex-rs/core/src/model_info.rs` resolves the review requirement from the
model's Guardian policy first:

```rust
pub fn computer_use_review_required(&self) -> bool {
    match self.guardian_review_mode(GuardianScope::ComputerUse) {
        Some(mode) => mode != GuardianReviewMode::Disabled,
        None => self.node_repl_auto_review_required,
    }
}
```

Turn metadata (Rust `with_window_and_fork_metadata`) reports that resolved
value, not the raw legacy flag.

## Go gap

`appserver/node_repl_evidence.go::nodeReplAutoReviewRequiredForModel` and the
compaction/web-search metadata paths already used
`ModelInfo.ComputerUseReviewRequired()`, but
`appserver/turn_runtime.go::appTurnConfigWithOptions` still read
`modelInfo.NodeReplAutoReviewRequired` directly, so a model that disables the
policy kept reporting `node_repl_auto_review_required: true` in the turn
metadata.

## Change

`appTurnConfigWithOptions` now resolves the flag through
`nodeReplAutoReviewRequiredForModel(modelInfo)`, which honors
`Guardian.ComputerUse` and falls back to the legacy bit only when the model has
no policy.
