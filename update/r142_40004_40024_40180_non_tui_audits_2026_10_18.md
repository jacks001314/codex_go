# Non-TUI audits: managed deny-read, granular approvals, context content kinds

## `#40004` Managed deny-read rules

Go merges managed deny-read rules into command-exec sandbox policy and rejects
request-specific policies that would weaken or conflict with them. App-server
command-exec tests pass.

## `#40024` Granular unified-exec approvals

Unified exec honors the granular `sandbox_approval` sub-policy, allowing
escalation to prompt when permitted while still rejecting disallowed escalation.
Tool shell tests pass.

## `#40180` Contextual fragment content kinds

Context fragments are classified with harness-owned content kinds and the
classification is preserved through app-server rendering. Context and
app-server tests pass.

## Verification

- `go test ./appserver -run 'ManagedDenyRead|DenyRead|CommandExec' -count=1`
- `go test ./tool -run 'Granular|SandboxApproval|Escalation' -count=1`
- `go test ./context ./appserver -run 'Contextual|ContentKind|Fragment' -count=1`
