### 3-A8.6 N-A 说明：Unix 臂 `readlink == protected_socket_path` 半无 Go 载体（正向证据）

Rust Unix 臂的**第一道**闸门是 `read_link(advertised) == protected_socket_path(advertised)`（`unix_socket.rs:306-309`），而 `protected_socket_path` 是 `sha2` 派生的受保护路径（同文件 `:329-333` 起），只有 daemon 通过 rendezvous 符号链接暴露控制 socket 时才成立。Go 侧正向证据（`grep`，在本 worktree 执行）：

```
> Select-String -Path ./**/*.go -Pattern 'protectedSocketPath|ProtectedSocket|protected_socket_path'
appserver\unix_socket_unix.go:43  // protected_socket_path), which is what rejects an SSH/socat forward bound   <- 仅本项注释
appserver\unix_socket_unix.go:45  // socket directly and Go has no protected-path derivation (no protectedSocketPath
```

即 Go 侧**没有** `protectedSocketPath` / `protected_socket_path` 派生或 rendezvous→受保护路径的等价载体；Go daemon 直接把控制 socket bind 在 advertised 路径上（`codexuds/platform_other.go` 的 `validatePrivateSocketPath` 只做 `filepath.Abs`，见下），因此不存在「advertised 是符号链接、目标是受保护路径」这一状态，`readlink` 断言在 Go 上恒不成立/无对象可判。

```
> Select-String -Path ./codexuds/platform_other.go -Pattern 'func validatePrivateSocketPath' -Context 0,7
func validatePrivateSocketPath(socketPath string) (string, *os.File, error) {
	absolute, err := filepath.Abs(strings.TrimSpace(socketPath))
	if err != nil {
		return "", nil, err
	}
	return absolute, nil, nil
}
```

`codexuds` 里唯一的符号链接逻辑是长路径 `EINVAL` 重试（`platform_other.go:77-91` 注释 + `filepath.EvalSymlinks`，配套 `uds_unix_test.go:15-48`），与「受保护路径派生」无关。

**因此 A8 在 Go 侧的落点取 Rust 用例真正能在本平台成立的两条语义**：(1) 显式默认 socket 必须存在，否则报 Rust 原文 `"the requested app-server socket is not available"`；(2) 只有**校验通过**的默认 daemon socket 才算本地（Windows 走 `ValidatePrivateSocketPath` 目录 DACL，Unix 走目录 uid/0700 契约），路径本身不再是「本地」的充分条件。Rust 用例里 `UnixListener::bind` 同一路径⇒`None`（`unix_socket_tests.rs:434-439`）对应到 Go 的等价负例是「目录未通过私有化校验⇒不 verified」（`daemon_socket_locality_like_rust_test.go:42` 与 RC-B 原文），已在测试里显式断言。
