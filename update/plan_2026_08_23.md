### `4582c0a498` #40196 Annotate user input and contextual fragments with content kinds

  writing `content_item_kinds` into message metadata.
- Go mapping: in the user-input message builder, derive a `content_item_kinds` slice

  `build_rendered_message`).
- Go mapping: the developer/contextual message builder merges rendered fragments and writes
  the combined content-kind list into metadata.

  `compaction.auto_fallback_prompt`, `{section_id}.instructions`, `generic.developer_instructions`,
  `guardian.policy`, etc.).
