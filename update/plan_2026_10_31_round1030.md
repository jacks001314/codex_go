## Goal

Audit #41923 (per-call sideband endpoints for existing realtime calls) and
close the missing in-process endpoint override in Go.

## Findings

- Go already joins client-created calls through `ExistingCallTransport` and the
  realtime `Manager`, using the configured `experimental_realtime_ws_base_url`
  (defaulting to the public API) as the sideband endpoint. The call-specific V1
  handshake query and V3 `/v1/live/<call>` path, activation retries
  (#51460), and runtime `CallHeaders` without bearer authorization (#57817)
  were already present.
- The missing piece was the in-process `sideband_base_url` override. Go's
  `StartTransport` only carried `type`, `sdp`, and `callId`, so an embedder
  could only change the manager-wide endpoint, which also affects other
  transports, or replace the whole backend.
- Upstream keeps app-server requests on the configured or default endpoint and
  applies the override only to the existing call's sideband, falling back to
  `experimental_realtime_ws_base_url` when absent.

## Implementation

- `realtime.StartTransport` now carries `SidebandBaseURL` marked `json:"-"`. It
  is in-process metadata: it is never marshaled and a client-supplied
  `sidebandBaseUrl` field is ignored on decode.
- Added `ExistingCallTransportWithSideband(callID, sidebandBaseURL)`.
- `realtimeSidebandBackendForTransport` applies the override only for
  `existingCall` transports, cloning the configured backend so its HTTP client,
  query params, and runtime headers survive. Starting and reconnecting the
  sideband both use the resulting backend, so a reconnect stays on the per-call
  endpoint.
- App-server `thread/realtime/start` still passes no override, matching Rust's
  `message_processor` behaviour; embeddings that call the realtime package
  directly can supply it.

## Tests

- `realtime/existing_call_test.go`:
  - `TestExistingCallSidebandEndpointIsNotWireSerializedLikeRust` pins the
    unchanged wire shape and rejects a client-injected `sidebandBaseUrl`.
  - `TestExistingCallSidebandPrefersPerCallEndpointLikeRust` proves the
    per-call server receives the handshake, the configured server receives
    none, and runtime auth headers are preserved without `Authorization`.
  - `TestExistingCallSidebandReconnectsToPerCallEndpointLikeRust` forces a V3
    sideband reconnect and asserts both connections hit the per-call endpoint.
