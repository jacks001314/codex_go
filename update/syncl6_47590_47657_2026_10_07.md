Rust 原文（`codex-rs/codex-api/src/common.rs`）：

```
 pub struct Reasoning {
-    #[serde(skip_serializing_if = "Option::is_none")]
+    #[serde(
+        skip_serializing_if = "Option::is_none",
+        serialize_with = "serialize_reasoning_effort"
+    )]
     pub effort: Option<ReasoningEffortConfig>,
...
+fn serialize_reasoning_effort<S>(effort: &Option<ReasoningEffortConfig>, serializer: S)
+    -> Result<S::Ok, S::Error>
+{
+    if let Some(ReasoningEffortConfig::Custom(value)) = effort
+        && let Ok(value) = value.parse::<u64>()
+    { return serializer.serialize_u64(value); }
+    effort.serialize(serializer)
+}
```

语义：**命名档位（Named）保持 JSON 字符串**；**`Custom` 且能 `parse::<u64>()` 的值改为 JSON number**；其余（非数字 / 超 u64 / 负号）仍是字符串。

```

origin/main:model/responses_agent.go:331:	Summary string `json:"summary,omitempty"`
```

`Effort` 是 `string` + `omitempty` ⇒ **恒发字符串**。custom 值确实会到达线上：`model/reasoning_effort.go`
的 `ResolveReasoningEffort` 只对 `ultra` / `persistent` 特判，其余原样透传；`IsKnownReasoningEffort`
之外即 custom。故 `model_reasoning_effort = "64"` 在 Go 发 `"effort":"64"`，Rust 发 `"effort":64`。

### 1.3 落点与实现（`model/responses_agent.go`）

- 结构体 `responsesReasoning` 之上新增 **`MarshalJSON`**（值接收者，`*responsesReasoning` 亦满足 `json.Marshaler`），
  内部用一个 `Effort json.RawMessage` 的匿名 wire 结构保持 **字段顺序 / omitempty 不变**；命名档位输出逐字节不变。
- 新增 `reasoningEffortJSONValue(string) (json.RawMessage, error)`：
  - 空串 ⇒ `nil`（omitempty 省略，与改前一致）；
  - `!IsKnownReasoningEffort(...)` 且 `strconv.ParseUint(TrimPrefix(effort,"+"),10,64)` 成功 ⇒
    `json.RawMessage(strconv.FormatUint(value,10))`（**canonical 十进制**，故 `+007`→`7`；Rust `serialize_u64` 同）；
  - 其它 ⇒ `json.Marshal(effort)`（字符串）。
- 覆盖全部三条生产接线（改前行号）：`responses_agent.go:775`（WS 建连）/ `:1024`（HTTP 流式）/ `:1553`（非流式）都走同一个
  `responsesReasoningParam` → 同一 `responsesReasoning` 类型。

**与 Rust 的边界对照**（逐项，均写进回归测试）：`high`/`none`/`disabled`/`ultra` → 字符串；`64`/`0` → 数字；
`+7`/`007` → `7`（Rust `u64::from_str` 接受单个前导 `+`）；`18446744073709551615`（u64::MAX）→ 数字；
`-1` / `18446744073709551616` / `+` / `experimental` → 字符串。
