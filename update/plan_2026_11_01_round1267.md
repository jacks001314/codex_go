## Real gap closed (#58165)

Remote plugin bundle download URLs can carry signature tokens in their query
string. Rust #58165 keeps them out of every diagnostic. Go echoed the URL in
`validateRemotePluginBundleURL`, in the request error (via `net/url.Error`) and
in the redirect check.

`appserver/plugin_remote_bundle.go` now:

- reports `invalid remote plugin bundle URL: <parse cause>` without the input;
- names only the download host in request, status and size-limit errors;
- reports the redirect scheme instead of the final signed URL;
- wraps transport errors in `sanitizedRemotePluginBundleError`, which keeps the
  `errors.Is`/`errors.As` chain but drops the URL from the message.

The signed query is still sent on the wire, matching Rust.
