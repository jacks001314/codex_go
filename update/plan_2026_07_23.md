## Implementation notes

Go persists thread metadata in its JSON session store rather than Rust's SQLite thread table.
The external v2 protocol and update/list semantics are aligned; existing records decode with
`is_pinned` absent and therefore default to false. Pin-only metadata updates do not append to the
rollout file or invoke the Rust-compatible SQLite git metadata helper.
