Target: Rust `main` at `cbe16d525c2d7362fc3d4726143288e932905daa`.

## Scope

Audit the nine remaining non-TUI `audit_pending` commits. Eight belong to the
Windows sandbox provisioning service/protocol/client created by #42334, #42337
and #42341, which Go does not have; one adds the native Windows MXC adapter.

## Classifications

- `301a7c5e` (#42334) `not_applicable`: provisioning wire format
  (`ProvisioningMessage`, `FramedProvisioningMessage`,
  `PROVISIONING_PROTOCOL_VERSION`, `SANDBOX_PROVISIONING_PIPE_NAME`,
  `sandbox_setup_is_complete_with_settings`) exists only for the absent service
  and client. Go keeps its own elevated IPC framing and marker comparison.
- `dcfcb570` (#42337) `not_applicable`: the authenticated provisioning client
  (pipe server verification against `CodexSandboxService`, versioned exchange,
  busy/timeout classification, `WindowsSandboxProvisioningSettings`/
  `WindowsSandboxProxyListeners`) has no service or pipe to talk to.
- `501931b3` (#42341) `not_applicable`: creates the
  `codex-rs/windows-sandbox-service` crate (service host, IPC, lifecycle). Go
  has no service binary or SCM integration; setup stays the elevated helper.
- `c530382c` (#47673) `not_applicable`: splits registered-runner receipt
  authorization into owner / Codex home / removal-in-progress / incomplete
  setup errors. Go has no installation record or registered runner receipt.
- `731d4a5c` (#47922) `not_applicable`: lets full-access requests reach the
  service when registered Core is requested. Go has no service branch;
  registered Core rejects helper-owned provisioning instead.
- `06f97622` (#48531) `not_applicable`: adds context labels inside the
  service's runtime package registration.
- `e6f4af1d` (#48829) `not_applicable`: waits up to five seconds for the
  service to leave `SERVICE_START_PENDING`; Go never waits on a service.
- `5a5a4aa7` (#49067) `not_applicable`: sanitizes the service's policy
  rejection event; Go emits no service policy events.
- `60888d08` (#42841) `blocked_precondition`: the native MXC adapter launches
  through Microsoft MXC crates (`wxc_common`, `appcontainer_common`,
  `learning_mode_windows`). Go's `sandbox/mxc` fails closed with
  `NativeUnavailableMessage` and `execserver` reports `windowsMxc` false,
  consistent with the #55378 block.
