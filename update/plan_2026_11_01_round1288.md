# Round 1288 — every exec observes a cell, like Rust's session-backed exec

## Advanced this round

Rust has no unobserved exec path. `CodeModeExecuteHandler::execute` always goes
through `code_mode_service.execute`, which starts a cell and observes it with
`ObserveMode::YieldAfter(resolve_yield_timeout(yield_time_ms))`
(`code-mode-runtime/src/service.rs`):

```rust
let yield_time_ms = request.yield_time_ms.unwrap_or(DEFAULT_EXEC_YIELD_TIME_MS);
let started = self.runtime
    .execute(
        runtime_request(request, self.options.output_truncation),
        runtime::ObserveMode::YieldAfter(self.resolve_yield_timeout(yield_time_ms))
            .with_yield_signal(preempt.unwrap_or_default()),
        Arc::new(ProtocolDelegate { delegate }),
    )
    .await
    .map_err(|error| error.to_string())?;
```

Go kept a synchronous fast path for the common case (`yield_time_ms` omitted, no
`yield_control`, no preempt signal). It called `executeScript` inline with a nil
cell, which produced three divergences:

- a script that outlived its yield time blocked the tool call instead of
  returning `Script running with cell ID ...` after the yield window;
- a promise that never settles failed with Go's own
  `JavaScript execution did not settle` instead of leaving a cell running that
  the model can `wait` on or terminate;
- no `CellStarted`/observation facts were published for those calls, so
  telemetry and the wait surface missed them.

## What changed

- `tool/code_mode_exec.go`: removed the synchronous fast path from
  `codeModeExecExecutor.execute`; every exec now starts an observable cell and
  honours the yield timeout / preempt signal exactly like the already-cell
  paths (remote runtime and `code_mode_host` requests).
- `tool/code_mode_exec.go`: `installContentHelpers` takes the cell and records
  `image()`, `audio()` and `generatedImage()` items in the cell's incremental
  content view, so a cell-backed response still reports the media items the
  script produced (the fast path previously read them from its local slice).
