# `#42150` Support remote marketplaces in the plugin CLI

Rust 依据：`6b59cefcbb35951c197a235dc94dbe700f2fbc7c`。

## 落地内容

- `plugin/remote_catalog.go`：
  - `GET {chatgpt_base_url}/ps/plugins/list`，支持 `scope`
    (`GLOBAL`/`USER`/`WORKSPACE`)、`collection`、`pageToken` 分页；
  - 请求头携带 ChatGPT access token、account id、product SKU；
  - 按 base URL + account + scope + collection 生成 sha256 缓存键，
    10 分钟 TTL，force refresh 可绕过；
  - `POST /ps/plugins/{id}/install`（`includeAppsNeedingAuth=true`）与
    `POST /ps/plugins/{id}/uninstall`，校验返回 id/enabled；
  - `GET /ps/plugins/{id}?includeDownloadUrls=true` 获取 bundle URL 与
    app manifest。
- `plugin list`：
  - 显式选择 remote marketplace 时展示 catalog entries；请求失败直接返回；
  - 未限定 marketplace 时尝试 global remote catalog，失败则保留本地 curated
    catalog；
  - JSON/text 输出包含 remote source、version、install policy、auth policy。
- `plugin add`：
  - 调用 remote install mutation；
  - 获取 bundle detail，经 `appserver.InstallRemotePluginBundle` 下载并
    materialize；
  - 注册 remote detail 到共享 `PluginService` 并写入本地 installed config。
- `plugin remove`：先调用 remote uninstall mutation，再移除本地缓存/config。
- CLI context 根据 auth mode 设置 curated runtime route，ChatGPT auth 可看到
  remote marketplaces。
