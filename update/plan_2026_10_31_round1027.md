## Findings

- #41901 is covered by Go's full rollout replay:
  - `rollout/context_baseline.go` already treats a full `WorldState` snapshot
    that survives the segment's latest compaction, paired with a compatible
    `turn_context`, as a durable baseline.
  - Go reads the complete rollout on resume rather than performing Rust's
    paginated reverse scan, so the bounded and full replay paths converge on
    the same observable result. The upstream scan itself was later replaced by
    #47365, which also stops directly at the latest reconstructable compaction.
  - The previously missing coverage was the empty wake-turn shape. This round
    adds repeated wake turns across successive compactions and verifies the
    newest snapshot and resume settings win.
- #42076's Rust module split does not map one-to-one to Go, but the observable
  contract is present in `state/guardian.go`:
  - `BuildPromptPartsWithSectionCosts` collects root conversation, trusted user
    answers, and the conversation transcript in shared order for both
    `ActionPresentationSyncFull` and `ActionPresentationAsync`.
  - `RootMessage.Render` and `TrustedUserAnswersSectionItems` preserve source
    role labels while delivering the evidence as user-role context.
  - Prompt construction returns an error rather than a partial prompt when the
    composed action or section inputs are invalid.
  - `guardiancontext` remains the shared typed/reusable primitive package, but
    the sync and async request compilers intentionally share the state-level
    composer in this port.
- #49280 exposed a real Go gap: an explicit empty environment selection was
  treated like an absent selection, so retained capability roots could connect
  an executor that the turn did not capture.
  - `restrictCapabilityRootsToSelections` now distinguishes `nil` (legacy/unset)
    from a non-nil empty list (explicitly no captured environments).
  - Filtering still happens before attachment-root combination, ID deduplication,
    and readiness resolution, so a stale root cannot shadow a selected root with
    the same ID.
