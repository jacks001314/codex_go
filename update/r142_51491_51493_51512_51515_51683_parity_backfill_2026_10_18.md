## `#51491` Executor capability-root ownership

Ownership classification is independent of manifest parsing: malformed ancestor
manifests count as plugin ownership, nested manifests as parent ownership,
conclusive discovery results are required, and probe failures are surfaced
rather than misclassified as standalone.

## `#51493` Capability roots bound to environment selections

`EnvironmentCapabilityRoots` retains original indexes across environment splits.
Root restriction follows captured selections, thread requests reselect retained
roots, and each step snapshots the resulting ready roots. Workspace identity
ignores capability-root/config-only differences.

## `#51512` Windows sandbox temp environment

`:tmpdir` resolves only from absolute workload `TEMP`/`TMP` values with
deterministic case-insensitive deduplication. Permission grants and the child
environment use the same ordered entries.

## `#51515` Agent-tree shutdown failure reports

The public report carries bounded payload-free failures with operation, phase,
and thread classifications, an omitted count, and propagation through agent tool
results.

## `#51683` Stale Guardian reviewer rollback

Each review attempt checkpoints the last committed response/seed. A completed
allow invalidated by changed authorization restores that checkpoint on retry and
exhaustion, preventing the stale response ID from parenting the refreshed review.
