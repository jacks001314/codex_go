# Rust #51511: Windows drive-letter no-follow opens

Upstream commit: `9545947c6da3f8ecc9a94eefd3d81e8799f185ec`

## Result

Equivalent implementation with a different Windows carrier.

- Go does not construct the strict `\??\C:\` NT alias that Windows 10 rejected,
  so it does not need the upstream verified-volume-root retry.
- Regular-file opens call Win32 `CreateFile` on the ordinary DOS path with
  `FILE_FLAG_OPEN_REPARSE_POINT`.
- No-follow access walks every path component and rejects Windows reparse
  attributes, covering junctions that `os.ModeSymlink` does not report.
- The drive root is not treated as a reparse component; junction reads, opens,
  and creates remain blocked without touching the target.

## Verification

```text
go test ./execserver -run 'NoFollow|Volume|Reparse|RegularFile' -count=1
```

Passed on 2026-10-18.
