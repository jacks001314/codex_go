# Parity backfill: queued mail, attachment owners, output caps, world state, Guardian checkpoints

Five ledger-complete entries were still pending in parity. Their focused
regressions pass against the current tree.

## `#50087` Queued agent mail across eviction

Queue-only agent mail lives in the router's thread-keyed `agentMessages` map,
independent of loaded-session residency. Unload preserves order, follow-up
delivery drains retained mail first, and thread deletion/tree close/runtime
shutdown discard retained mail.

## `#50094` Attachment owner lookup

`thread/attachmentOwner/list` is an experimental RPC with attachment type,
identity key, archive filter, limit, and opaque cursor. It returns stable owner
pages and validates unavailable state and cursors.

## `#50427` Persisted command-output cap

The shared persisted-item projection caps paginated command output at 64 KiB
including its marker, uses UTF-8-safe middle truncation, and is applied before
durable append.

## `#50441` Ordered world-state response items

`session.WorldStateUpdate` preserves ordered mergeable/prefix transitions and
typed text/image/audio content. Merge, fragment hashing, and diff rendering keep
one positional content kind per emitted item.

## `#51137` Guardian parent-checkpoint recovery

The reviewer resets/seeds after parent compaction from a reusable checkpoint
response ID, drops incompatible or over-budget checkpoints, and preserves the
existing reviewer when no reusable checkpoint exists.
