# Round 116 · #45982 native DNS for the macOS network proxy

Rust source: `53401a2808`.

## Landed

- Split the proxy DNS lookup into platform files. The non-macOS implementation
  keeps `net.DefaultResolver.LookupIPAddr` unchanged.
- On macOS, `proxyLookupIPAddr` now resolves with `net.Resolver{PreferGo:
  false}`, selecting the cgo system resolver when available. That resolver
  sees macOS supplemental resolvers and VPN split DNS, which the pure Go
  resolver (reading `/etc/resolv.conf`) misses. It falls back to the default
  resolver only when cgo is unavailable; cancellation is preserved.
- The injectable package-level variable is retained so DNS scripting tests
  continue to prove blocked hosts never reach DNS. Go's proxy performs no TXT
  lookups, so Rust's "reject unsupported TXT lookups" branch has no carrier.
  Upstream-proxy connections already resolve through the same system dial path.
