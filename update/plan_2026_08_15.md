   - `config.Override.IgnoreProjectConfig` bypasses project-root discovery and

   - Cached/lazy MCP tool definitions keep their `namespaceDescription`

   - Go analytics event keeps added/deleted line counts and drops per-line

   - `appserver` hook discovery no longer skips `mcp_tool` handlers; it lists
     server/tool/input and the hooks runner executes them through the session
     MCP tool call path.

   - `appserver` hook discovery reflects plugin-contributed hook handlers
     without a stale runtime cache.

    - Plugin instruction rendering prefers the selected plugin's own apps
      before the global app catalog.

    - Rollout/state risk-score lines use the Rust snapshot shape.

      pasted line break becomes a single LF.
