# Non-TUI audits: enterprise OIDC, per-app tool exposure, deny-read ACL recovery

## `#43844` Enterprise OIDC login

Go resolves enterprise authorization metadata strictly, stages credentials until
the callback commits, captures the OIDC ID token, validates callback settings and
resource parameters, and invalidates a staged attempt on logout/token deletion.
MCP enterprise-OAuth tests pass.

## `#46035` Per-app tool exposure

`apps.<connector_id>.omit_tools_from` is parsed and validated, serialized through
the app config surface, and combined with server-level omissions in the tool
spec plan. Apps, config, and turn tests pass.

## `#50940` Malformed Windows deny-read ACL state

Go recovers malformed deny-read bookkeeping, propagates real I/O errors, rejects
linked state files, preserves file identity, and waits for/respects a legacy or
active writer before rebuilding reconciliation state. Windows sandbox tests pass.

- `go test ./mcp -run 'EnterpriseOAuth|EnterpriseAuthorization|CommitEnterprise|OAuthTokenSet' -count=1`
- `go test ./apps ./config ./turn -run 'OmitToolsFrom|ConnectorToolExposure|PerApp' -count=1`
- `go test ./sandbox/windowssandbox -run 'DenyReadACLState|DenyRead' -count=1`
