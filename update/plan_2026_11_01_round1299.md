## The gap

Rust's `prepare_image` only replaces the reference:

```rust
*image = match image_store.upload(request).await {
    Ok(UploadResult::File { file_id }) => ImageReference::File { file_id },
    ...
};
```

`detail` is left untouched, and `resize_image` writes the original-detail
compatibility hint only under `ImagePreparationMode::UnifiedBudget`. So a stored
request image serializes `file_id` together with the captured detail hint (or
`original` under the unified budget). Go deleted `detail` whenever the
attachment store returned a file reference, losing the hint that keeps
context-window accounting accurate.
