# Rust #54170: preserve ChatGPT authentication for Gov MCP servers

Upstream commit: `160b2b1ef62114eeb41e41e5e3be0000d944b713`

## Result

Implemented trusted-origin normalization for hosted MCP authentication.

- Streamable HTTP MCP servers requesting `auth=chatgpt` retain that auth only
  when their normalized origin is:
  - `https://chatgpt.com`
  - `https://gov.chatgpt.com`
  - the configured `chatgpt_base_url` when it is HTTPS on
    `chatgpt-staging.com` or a subdomain.
- Origin comparison normalizes host casing and default HTTPS ports. HTTP,
  non-default ports, lookalike hosts, subdomains of fixed origins, trailing
  dots, and userinfo-based spoofing do not qualify.
- Non-trusted servers fall back to OAuth rather than receiving the host's
  ChatGPT credential. Custom OAuth and local Apps registrations are unchanged.
- Gov Apps materialization uses the expected `/backend-api/ps/mcp` endpoint and
  retains ChatGPT auth.
