# Non-TUI audits: compaction fallback, cyber access, root turn IDs

## `#46324` Compaction fallback to current model

Go records the previous turn's model/context hash and retries a failed
compaction with the selected current model after interruption or budget stop.
App-server previous-model integration tests pass.

## `#49714` API-key cyber access programs

`api_key_cyber_access_programs` is decoupled from model discovery and only
admits a program for the OpenAI provider; wire and access-program tests pass.

## `#51421` Root turn IDs in host-owned Apps calls

The host-owned `codex_apps` registration receives the issuing turn's root turn
id in MCP turn metadata, while user-configured Apps servers omit it. Turn, MCP,
and app-server tests pass.
