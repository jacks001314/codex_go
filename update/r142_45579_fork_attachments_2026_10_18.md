# #45579 Copy current thread attachments into non-ephemeral forks

## Upstream change

A non-ephemeral thread fork copies the source thread's current attachments
with fresh IDs and creation timestamps. Fork and source memberships then
diverge independently, while ephemeral forks inherit no attachments.

## Go status

Complete by equivalent implementation.

`applyThreadForkAttachments` copies the source attachments before the fork is
published. `thread_attachments_fork_test.go` verifies copied identity/payload,
fresh IDs, independent removal, and the empty attachment set for ephemeral
forks.
