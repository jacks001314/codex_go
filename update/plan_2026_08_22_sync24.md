## Per-commit catalog

### `343074d420` #40068 Report runtime MCP connection status

- Adds `McpServerConnectionStatus` = `notStarted | starting | connected |
  authenticationRequired | failed | cancelled | disabled`.
- Adds nullable `runtimeStatus` to `mcpServerStatus/list` / `McpServerStatus`
  (thread-scoped). With no thread the map is empty -> `null` (renders "unknown").
- Observe published connection state without starting or reconnecting servers.
- Compact `/mcp` shows connection state + tool count (e.g. `connected (0 tools)`),
  "Use /mcp verbose for tools and resources." hint, and keeps full inventory in detail.
- Go mapping: `mcp/api.go` type + `MCPServerStatus.RuntimeStatus` + `MarshalJSON`;
  `ListStatusChecked` derives the status from the thread-scoped `MCPService`
  state (starting/ready/failed/cancelled/stopped + auth/failure reason);
  `app/interactive.go` and `tui/history_cell/mcp.go` render the compact status.

### `4f39251a01` #40038 Add unfinished root turn suspension

- Adds `CodexThread::suspend_turn_and_shutdown` + `SuspendTurnOutcome`
  (`Suspended{turn_id}` / `NotActive` / `HasLiveDescendants` / `UnsupportedTask`).
- Stops an active regular root turn without recording a terminal turn event, so
  another worker can recover the original turn ID. Flushes history, stops the task,
  closes the writer, shuts down the session, emits `ShutdownComplete`.
- Rejects suspension when no supported turn is active or a live descendant exists.
- Go mapping: new app-server method (e.g. `thread/suspendTurn`), a session/runtime
  suspend handler that cancels the active regular task without terminal-event
  recording, and the `SuspendTurnOutcome` wire enum.
- **Deferred to batch2** in this sync (see roadmap).
